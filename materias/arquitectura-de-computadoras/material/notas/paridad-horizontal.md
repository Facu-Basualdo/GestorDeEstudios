# Paridad Horizontal a Nivel de Bloque

> Modalidad de paridad que crea un byte con bits de paridad por cada bloque de caracteres.

El bit 0 será el bit de paridad de los bits 0 del bloque; el bit 1, el de paridad de los bits 1 del bloque, y así sucesivamente.
