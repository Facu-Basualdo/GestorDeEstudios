# Direccionamiento Indexado

> Modo de direccionamiento en el que el campo Dir sitúa al operando en relación a una dirección de referencia usando un Registro Índice.

Dirección Efectiva = Desplazamiento ± Registro Índice

El mecanismo es el mismo que en base-desplazamiento, con la diferencia de que el valor del registro índice se suele modificar con frecuencia durante la ejecución de un programa, mientras que el base no.

Permite recorrer estructuras de datos tipo vector o tabla.
