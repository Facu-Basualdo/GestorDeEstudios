# Códigos Redundantes

> Sistemas de codificación que agregan redundancia al mensaje enviado para que el receptor pueda verificar si el mensaje es correcto o no.

Son utilizados con fines de encriptación y de seguridad del mensaje. La idea es agregar la mínima redundancia para que no afecte demasiado al tamaño del paquete.

Información = Log2(10) = 3,162… ≈ 4: cualquier código para representar los números del sistema decimal precisará, como mínimo, 4 dígitos binarios. Cuando el código utilice más dígitos que los que necesita, se denomina código redundante.
