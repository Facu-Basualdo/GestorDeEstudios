# Ecuaciones de señales para la operación (P) → S

> Regla de timing de las señales que implementan la operación (P) → S: deben activarse cada dos batidos del clock, incluido el batido φ0.

Deben activarse cada dos batidos del clock, incluido el batido φ0, ya que Abacus trabaja con un distribuidor de dos fases.

El texto incluye un esquema con DECO, ciclo de búsqueda de instrucción y ciclo de búsqueda de operando.
