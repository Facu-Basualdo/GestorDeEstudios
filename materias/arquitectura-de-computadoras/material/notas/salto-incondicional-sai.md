# SAI – Salto Incondicional

> Instrucción del set de instrucciones que rompe la secuencia del contador de programa saltando a una dirección específica de memoria.

Es estricto. Se utiliza para romper la secuencia del contador de programa. Permite saltar a una dirección específica de memoria, dentro de la zona del programa. Junto con SAC, se coloca aparte del resto del set de instrucciones porque no va dirigido a la ALU: la orden es enviada directamente al Registro P.
