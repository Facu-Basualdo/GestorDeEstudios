# Ruta de Datos

> Conjunto de órganos que procesan información desde la memoria central mediante registros de transferencia y buses definidos.

La Unidad de Control, un órgano central, genera señales para coordinar el movimiento de instrucciones y datos en lenguaje de máquina binario. Este lenguaje, diferente del ensamblador, utiliza ceros y unos para indicar las operaciones de la máquina.
