# Registros Índices

> Registros SI y DI del 8086 que funcionan como punteros fuente y destino para operaciones con cadenas y para direccionamiento indirecto.

- **SI (Index Source / Índice Fuente)**: sirve como puntero fuente para operaciones con cadenas; lleva la dirección donde comienzan los datos que se quieren leer dentro de un segmento de datos. También sirve para direccionamiento indirecto.
- **DI (Index Destination / Índice Destino)**: sirve como puntero destino para operaciones con cadenas; lleva la dirección donde terminan los datos que se quieren leer dentro de un segmento de datos. También sirve para direccionamiento indirecto.
