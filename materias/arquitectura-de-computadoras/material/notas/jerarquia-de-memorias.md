# Jerarquía de Memorias

> Método de clasificación de las memorias existentes según su capacidad, tiempo de acceso y costo, cuyos niveles representan el campo de aplicación de cada familia.

Es un método de clasificación para tener una visión amplia de todas las memorias existentes. Se clasifican según su capacidad, tiempo de acceso y costo.

- En la cima: baja capacidad y bajo tiempo de acceso, alto costo.
- En la base: alta capacidad y alto tiempo de acceso, bajo costo.

Los niveles representan el campo de aplicación de cada familia de memoria, es decir, para qué se pueden utilizar las memorias.
