# Empaque

> Proceso de eliminar la parte de ZONA de cada byte en datos numéricos codificados para poder realizar operaciones aritméticas.

La información resultante se llama información empacada o decimal sin zona; los datos numéricos con zona se denominan información desempacada o zoneada. Se aplica tanto en EBCDIC como en ASCII, comúnmente con 8 bits por dígito.
