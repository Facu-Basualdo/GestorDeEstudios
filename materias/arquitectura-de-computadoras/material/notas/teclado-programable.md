# Teclado programable

> Teclado que incorpora un microcontrolador interno y un programa en ROM para interpretar las señales de las teclas.

Se comunica con la controladora de teclado de la placa base. Contiene un programa integrado en una ROM que interpreta las señales cuando se cierra el circuito entre las teclas y el circuito integrado. Puede almacenar datos adicionales en la ROM, como el código del teclado y la posición de las teclas. Requiere un controlador o driver para interpretar las señales y funcionar correctamente.
