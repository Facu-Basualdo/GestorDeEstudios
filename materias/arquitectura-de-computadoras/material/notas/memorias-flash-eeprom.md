# Memorias Flash / EEPROM

> Memorias del nivel 3 usadas para guardar la BIOS, más baratas que las RAM pero mucho menos veloces, destinadas a rutinas de bajo nivel.

En estas memorias se borran y escriben datos. Mientras que la memoria Flash opera en bloques y ofrece mayor velocidad para grandes cantidades de datos, la EEPROM permite la escritura a nivel de byte, brindando flexibilidad en la modificación de datos individuales.

Son utilizadas para guardar la BIOS, que está en la placa madre. Son un poco más baratas que las RAM pero también mucho menos veloces. No sirven para guardar datos de cálculo ni programas, sino más bien rutinas de bajo nivel necesarias para que la máquina pueda operar.
