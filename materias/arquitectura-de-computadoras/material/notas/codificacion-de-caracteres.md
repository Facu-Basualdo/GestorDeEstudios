# Codificación de Caracteres

> Extensión de la codificación de números a letras, signos y caracteres especiales.

Condiciones para codificación:
1. Debe englobar cifras y permitir distinguirlas rápidamente.
2. Permite añadir nuevos caracteres específicos.
3. Para transmisiones, debe tener redundancia para detectar errores.
