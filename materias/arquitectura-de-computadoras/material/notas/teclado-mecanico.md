# Teclado mecánico

> Tipo de teclado de contacto que utiliza interruptores individuales para cada tecla, cerrando un circuito al presionar.

Al presionar una tecla, se cierra el interruptor permitiendo el paso de corriente. Es vulnerable a la suciedad y propenso a fallas con el tiempo.
