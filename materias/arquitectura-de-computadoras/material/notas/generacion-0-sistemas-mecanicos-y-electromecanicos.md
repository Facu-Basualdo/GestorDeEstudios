# Generación 0: Sistemas Mecánicos y Electromecánicos

> Generación 0 (hasta 1945) comprende los sistemas mecánicos y electromecánicos, como ábacos, calculadoras mecánicas y sistemas basados en relés.

Características de la Generación 0:

- **Ábacos**: uso de ábacos, un sumador mecánico con bolitas, como una de las primeras herramientas para realizar cálculos.
- **Calculadoras Mecánicas**: desarrollo de calculadoras mecánicas que utilizan sistemas de ruedas y engranajes para realizar cálculos. Ejemplo notable: la Pascalina.
- **Sistemas Basados en Relés**: creación de sistemas electromecánicos basados en relés, que incorporan casi un millón de ruedas y casi mil kilómetros de cable para operar. Ejemplo representativo: Mark (Harvard).
