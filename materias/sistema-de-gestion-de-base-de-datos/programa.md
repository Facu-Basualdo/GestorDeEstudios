## Objetivos
Formar al estudiante para administrar, operar, optimizar, asegurar y seleccionar motores de bases de datos relacionales, NoSQL y cloud en escenarios reales. (Fuente: `Clase 0 - Introduccion.pdf`, p. 3)

## Régimen de Aprobación
(Fuente: `Clase 0 - Introduccion.pdf`, p. 10-11)

- **Aprobación Directa**:
  - 75% de asistencia a actividades obligatorias.
  - Todas las instancias previstas aprobadas (Parcial 1, Parcial 2 y laboratorio integrador con posibilidad de recuperar un parcial).
  - Actividades en clase obligatorias aprobadas.
  - Nota final igual o superior a 6.

- **Aprobación de Cursada**:
  - 75% de asistencia.
  - Aprobación de al menos el laboratorio integrador + una instancia de evaluación.
  - 75% de actividades formativas obligatorias.
  - Recuperatorios según condición, habilita a rendir examen final.

## Unidades y temas
(Fuente: `planificacion+.txt` y `cronograma.png`)

### Bloque Temático 1: Administración de Bases de Datos Relacionales
- **Tema 1:** Arquitectura e Instalación de un motor de base de datos relacional
- **Tema 2:** Diseño físico de una base de datos relacional
- **Tema 3:** Lenguaje SQL avanzado
- **Tema 4:** Herramientas de programación en los motores de base de datos relacionales
- **Tema 5:** Conectividad del RDBMS
- **Tema 6:** Seguridad, copias de resguardo y alta disponibilidad

### Bloque Temático 2: Bases de Datos NoSQL y en la Nube
- **Tema 7:** Datos Semiestructurados (XML y JSON)
- **Tema 8:** Introducción a los motores NoSQL
- **Tema 9:** Modelos de datos basados en Agregados y basados en Relaciones
- **Tema 10:** Modelos de distribución de datos
- **Tema 11:** Introducción a bases de datos en la nube
- **Tema 12:** Herramientas para almacenamiento, procesamiento y análisis de datos distribuidos
