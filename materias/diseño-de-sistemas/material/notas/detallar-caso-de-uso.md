# Detallar un caso de uso

> Actividad de la captura de requisitos que detalla un caso de uso, a partir del modelo de casos de uso esbozado, y produce un caso de uso detallado.

Según la Figura 7.14, las entradas son: el modelo de casos de uso (esbozado), el especificador de casos de uso, los requisitos adicionales y el glosario. El resultado es el caso de uso (detallado).
