# Estilos arquitectónicos

> Formas de organizar los componentes de un sistema distribuido, que también pueden considerarse patrones.

El material menciona el estilo **Maestro-Esclavo**, que se utilizaba mucho en el tema de las bases de datos. Los componentes distribuidos y los microservicios fueron haciendo una evolución de estos estilos.

Se comenta para que se sepa de dónde vienen; no quiere decir que todos se utilizan hoy en día.
