# Dirigido por casos de uso

> Es una característica innegociable del Proceso Unificado por la cual el desarrollo se guía a partir de casos de uso.

Hablar de PU sin casos de uso es imposible; es una de las tres características innegociables. A partir de los casos de uso se desarrollan el resto de las disciplinas. Se toma un caso de uso y se analizan sus partes estáticas y dinámicas. La **Realización de CU** es una parte importante pero pequeña dentro de todo el caso de uso. Este enfoque permite hacer los requerimientos, el diseño, la implementación y luego las pruebas.
