# Pattern Language

> Conjunto estructurado de patrones que, aplicados en un orden predeterminado, generan edificios o comunidades completas, según Christopher Alexander.

Christopher Alexander desarrolló el concepto de pattern language para la arquitectura. Según Alexander, un pattern language proporciona una guía paso a paso para diseñar edificios, enfatizando los problemas que cada patrón resuelve. El autor establece un orden para usar los patrones y afirma que generan edificios completos. En contraste, los design patterns en software se centran más en las soluciones y no pretenden generar programas completos. El trabajo de Alexander influyó en los autores para considerar los trade-offs y las fuerzas en el diseño, pero no consideran su catálogo como un pattern language completo.
