# Tactics-Based Questionnaire for Deployability

> Cuestionario basado en tácticas que el analista utiliza para obtener un panorama de las decisiones arquitectónicas que soportan la desplegabilidad de un sistema.

El cuestionario se presenta en la Table 5.2. Para usarlo, el analista formula cada pregunta y registra las respuestas en la tabla. Las respuestas pueden ser luego el foco de actividades posteriores: investigación de documentación, análisis de código u otros artefactos, ingeniería inversa del código, entre otras.
