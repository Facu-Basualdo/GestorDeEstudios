# Implementar prueba

> Actividad del proceso de pruebas, realizada por el Ingeniero de componentes, que produce el componente de prueba a partir del caso de prueba, el procedimiento de prueba y el modelo de implementación construido para ser probado.

El Ingeniero de componentes es el actor responsable.

- Entradas: Caso de prueba, Procedimiento de prueba, Modelo de implementación (construida para ser probada).
- Resultado: Componente de prueba.
