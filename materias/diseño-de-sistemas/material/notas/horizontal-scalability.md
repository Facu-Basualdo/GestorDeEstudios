# Horizontal Scalability

> Horizontal scalability (escalar hacia afuera) es agregar más recursos a unidades lógicas, como sumar otro servidor a un clúster de servidores.

También se denomina scaling out. En entornos de nube, este tipo de escalabilidad se llama elasticity. El problema que surge es cómo utilizar eficazmente los recursos adicionales.
