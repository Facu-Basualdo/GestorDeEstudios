# Estructuras de asignación

> Las estructuras de asignación modelan qué elementos del software se asignan a otros elementos que no son software.

Típicamente se representan muy bien con diagramas de despliegue de UML. Permite modelar qué elementos del software se asignan a otros elementos que no son software. En cuanto a la implementación, no solo es hardware: se pueden asignar módulos a otras variantes.
