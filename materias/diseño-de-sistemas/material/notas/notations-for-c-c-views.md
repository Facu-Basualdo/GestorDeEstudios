# Notations for C&C Views

> La notación para C&C views establece pautas para representar este tipo de vistas, como asignar un símbolo separado a cada tipo de componente y a cada tipo de conector y listar los tipos en una clave.

Las vistas C&C se pueden representar con dibujos de cajas y líneas (box-and-line drawings), aunque las notaciones informales son limitadas en la semántica que pueden transmitir. La guía principal es asignar un símbolo separado a cada tipo de componente y a cada tipo de conector, y listar los tipos en una clave. Los componentes UML son un buen equivalente semántico a los componentes C&C porque permiten documentar de forma intuitiva información importante como interfaces, propiedades y descripciones de comportamiento. Los componentes UML también distinguen entre tipos de componente e instancias de componente, lo cual es útil para definir tipos de componente específicos de una vista.
