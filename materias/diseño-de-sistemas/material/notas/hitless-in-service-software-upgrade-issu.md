# Hitless In-Service Software Upgrade (ISSU)

> Actualización de software en servicio sin afectar el servicio, que aprovecha la táctica de redundant spare para lograr actualizaciones no perjudiciales del software y de esquemas asociados.

Se usa para entregar nuevas funcionalidades y capacidades, a diferencia del function patch y el class patch, que se usan para correcciones de errores.
