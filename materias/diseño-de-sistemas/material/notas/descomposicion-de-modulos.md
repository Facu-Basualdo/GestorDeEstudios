# Descomposición de módulos

> La descomposición de módulos es el proceso de asignar responsabilidades a los elementos para alcanzar la funcionalidad del sistema.

Aunque la funcionalidad es independiente de cualquier estructura, se llega a ella asignando responsabilidades a los elementos. Este proceso se denomina descomposición de módulos. El interés del arquitecto con respecto a la funcionalidad es cómo interactúa y restringe a las demás cualidades.
