# Increase Cohesion

> Increase Cohesion es un conjunto de tacticas que redistribuyen las responsabilidades entre modulos para reducir la probabilidad de que un solo cambio afecte a varios modulos.

Se toma este paso cuando un modulo que se modifica incluye responsabilidades que no son cohesivas. Incluye las tacticas Split Module y Redistribute Responsibilities.
