# View

> Una view (vista) es una representación de un conjunto de elementos del sistema y las relaciones entre ellos, limitado a un tipo particular de elementos.

Una arquitectura de software es una entidad multidimensional que no puede describirse de manera unidimensional. Las views permiten dividirla en representaciones manejables e interesantes. Por ejemplo, una vista en capas muestra elementos de tipo "capa" y las relaciones entre capas, pero no muestra servicios, clientes y servidores, ni el modelo de datos. La elección de views depende de los objetivos de la documentación: distintas views exponen distintos atributos de calidad. Por eso no se recomienda una view o colección particular; cada view tiene un costo y un beneficio, y se eligen según los usos esperados. Existen vistas de módulos, de componentes y conectores (C&C), de asignación y vistas de calidad. Principio básico: documentar una arquitectura es documentar las views relevantes y agregar documentación que aplique a más de una view.
