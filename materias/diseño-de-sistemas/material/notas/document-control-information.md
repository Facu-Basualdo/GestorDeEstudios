# Document Control Information

> Información que lista la organización emisora, la versión actual, la fecha de emisión y estado, el historial de cambios y el procedimiento para enviar solicitudes de cambio.

Generalmente esta información se captura en la portada (front matter). Las herramientas de control de cambios pueden proveer gran parte de esta información.
