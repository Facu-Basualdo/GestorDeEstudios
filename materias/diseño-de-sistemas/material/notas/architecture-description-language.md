# Architecture Description Language (ADL)

> Un ADL es una notación formal para describir arquitecturas de software que provee un vocabulario gráfico y una semántica subyacente para la representación de la arquitectura.

Los ADL son la variedad de notaciones formales disponibles para arquitectura de software. Pueden estar especializados en determinadas vistas o permitir varias vistas, incluso definir formalmente vistas nuevas. Su utilidad reside en la capacidad de soportar automatización a través de herramientas asociadas, por ejemplo para analizar la arquitectura o asistir en la generación de código. En la práctica, se usan raramente.
