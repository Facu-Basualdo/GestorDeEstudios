# Project Manager and Software Architect

> El gerente de proyecto y el arquitecto de software ocupan roles complementarios: el primero administra el proyecto desde una perspectiva administrativa y el segundo lo dirige desde la perspectiva de la solución técnica.

Según el resumen del capítulo, estos dos roles se intersectan de varias maneras y el arquitecto puede apoyar al gerente para aumentar las posibilidades de éxito del proyecto.
