# Software Reliability

> La confiabilidad del software es la probabilidad de operación libre de fallas de un programa en un entorno específico durante un tiempo específico.

La confiabilidad del software se puede medir directamente y estimar utilizando datos históricos y de desarrollo. Por ejemplo, si se estima que el programa X tiene una confiabilidad de 0.999 durante 8 horas de procesamiento, significa que si el programa se ejecuta 1000 veces y requiere un total de 8 horas de tiempo de procesamiento, es probable que funcione correctamente (sin fallas) 999 veces.
