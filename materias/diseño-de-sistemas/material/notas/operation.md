# Operation

> Recurso de las interfaces proporcionadas que se invoca para transferir control y datos al elemento para su procesamiento.

La mayoría de las operaciones también devuelven un resultado. Las operaciones pueden fallar, y como parte de la interfaz debería quedar claro cómo los actores pueden detectar errores, ya sea señalados como parte de la salida o mediante un canal dedicado de manejo de excepciones.
