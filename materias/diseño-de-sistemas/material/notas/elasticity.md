# Elasticity

> Capacidad del cloud de agregar y liberar recursos fácil y rápidamente, pagando solo por los recursos que se solicitan.

Junto con el pago por uso, la elasticidad permite crear sistemas con capacidad para manejar la carga de trabajo sin pagar capacidad excedente.
Aplica en distintas escalas de tiempo: para cargas estables se puede revisar y cambiar la asignación de recursos manualmente cada mes o trimestre; para cargas dinámicas se necesita automatizar la creación y liberación de instancias (autoscaling).
