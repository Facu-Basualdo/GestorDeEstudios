# Resource Syntax

> Sintaxis de un recurso: su firma, que incluye cualquier información que otro programa necesite para escribir un programa sintácticamente correcto que use el recurso.

La firma incluye el nombre del recurso, los nombres y tipos de datos de los argumentos, si los hay, y demás información necesaria.
