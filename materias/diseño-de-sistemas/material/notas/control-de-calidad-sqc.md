# Control de calidad (SQC)

> Control de calidad es controlar efectivamente el producto que se desarrolla; si el producto cumplió con los estándares, hay control de calidad.

- Se centra en el producto que desarrollamos, por ejemplo mediante testing.
- Si el producto cumplió con los estándares, se considera control de calidad.
