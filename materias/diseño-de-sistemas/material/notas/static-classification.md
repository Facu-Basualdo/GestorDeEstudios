# Static Classification

> Static classification estima el consumo de energía catalogando los recursos de cómputo utilizados y sus características energéticas conocidas.

Se usa cuando la recolección de datos en tiempo real es inviable; por ejemplo, en una nube fuera de las instalaciones no se tiene acceso directo a los datos energéticos en tiempo real.

Las características energéticas de los recursos (por ejemplo, la energía que usa un dispositivo de memoria por fetch) están disponibles como benchmarks o en las especificaciones del fabricante.
