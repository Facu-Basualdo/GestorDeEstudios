# Model Checking

> El model checking es una técnica que ejecuta simbólicamente todos los caminos de código posibles.

El tamaño de un sistema que puede validarse con model checking es limitado, pero los controladores de dispositivos y los microkernels han sido verificados con éxito mediante esta técnica.
