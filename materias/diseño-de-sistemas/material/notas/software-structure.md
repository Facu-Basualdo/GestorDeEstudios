# Software Structure

> Una software structure (estructura de software) es un conjunto de elementos unidos por una relación.

Una estructura es un conjunto de elementos mantenidos unidos por una relación. Los sistemas de software están compuestos por muchas estructuras, y ninguna estructura por sí sola puede reclamar ser la arquitectura.

No toda estructura de software es arquitectónica. Por ejemplo, el conjunto de líneas de código fuente que contienen la letra “z”, ordenadas de menor a mayor longitud, es una estructura de software, pero no es interesante ni arquitectónica. Una estructura es arquitectónica si apoya el razonamiento sobre el sistema y sus propiedades.
