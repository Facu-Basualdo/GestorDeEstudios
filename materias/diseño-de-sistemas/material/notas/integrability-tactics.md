# Integrability Tactics

> Las tácticas de integrabilidad son aquellas cuyo objetivo es reducir los costos y riesgos de agregar componentes nuevos, reintegrar componentes modificados e integrar conjuntos de componentes para cumplir requisitos evolutivos.

Las tácticas logran estos objetivos de dos maneras: reduciendo el número de dependencias potenciales entre componentes o reduciendo la distancia esperada entre componentes. La Figura 7.3 muestra un panorama de las tácticas de integrabilidad.
