# Software Architect

> Un software architect es mucho más que un diseñador de arquitecturas: debe cumplir deberes, desarrollar habilidades y adquirir conocimiento de manera continua para que una organización centrada en la arquitectura tenga éxito.

El arquitecto debe llevar a cabo los deberes, perfeccionar las habilidades y adquirir continuamente el conocimiento necesarios para tener éxito. La clave para convertirse en un buen arquitecto, y luego en uno mejor, es el aprendizaje continuo, la mentoría y ser mentorado.

Una arquitectura es mucho más que un plano técnico para un sistema; un arquitecto es mucho más que un diseñador de una arquitectura.
