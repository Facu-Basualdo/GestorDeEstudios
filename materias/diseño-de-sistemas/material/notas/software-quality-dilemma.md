# Software Quality Dilemma

> El dilema de la calidad del software es la tensión entre producir software de alta calidad y la limitación de tiempo y recursos.

Bertrand Meyer plantea el dilema: si produces un sistema con terrible calidad, pierdes porque nadie querrá comprarlo. Si dedicas tiempo infinito, esfuerzo extremo y grandes sumas de dinero para construir el software perfecto, tardarás tanto y será tan caro que tu negocio fracasará. La industria busca un punto medio donde el producto sea suficientemente bueno para no ser rechazado, pero sin excesivo perfeccionismo. La situación es real y representa un dilema para incluso las mejores organizaciones. Ante el dilema, se debe buscar equilibrio: suficiente esfuerzo para producir calidad aceptable sin hundir el proyecto.
