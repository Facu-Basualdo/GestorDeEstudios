# Reduce Coupling

> Reduce Coupling es un conjunto de tacticas que reducen el acoplamiento entre los modulos.

Estas tacticas se superponen con las tacticas de integrabilidad del capitulo 7, porque reducir dependencias entre componentes independientes (para integrabilidad) es similar a reducir el acoplamiento entre modulos (para modificabilidad). Incluyen: Encapsulate, Use an Intermediary, Abstract Common Services y Restrict Dependencies.
