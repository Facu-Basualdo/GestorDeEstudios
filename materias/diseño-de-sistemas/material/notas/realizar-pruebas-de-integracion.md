# Realizar pruebas de integración

> Actividad del proceso de pruebas, realizada por el Ingeniero de pruebas de integración, que ejecuta pruebas de integración y reporta defectos a partir del caso de prueba, el procedimiento de prueba, el componente de prueba y el modelo de implementación construido para ser probado.

El Ingeniero de pruebas de integración es el actor responsable.

- Entradas: Caso de prueba, Procedimiento de prueba, Componente de prueba, Modelo de implementación (construida para ser probada).
- Resultado: Defecto.
