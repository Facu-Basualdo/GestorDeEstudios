# Defect Amplification and Propagation

> Defect amplification and propagation describe how a single early error that is not uncovered can multiply into multiple errors later in the development process.

As a development team moves deeper into the software process, the cost of finding and fixing an error grows. This is exacerbated by defect amplification and propagation because a single error may become multiple errors downstream. The cost to find and fix multiple errors propagated by a single earlier error is substantially more significant than fixing the original error early.
