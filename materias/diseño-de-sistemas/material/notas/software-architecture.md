# Software Architecture

> Software Architecture (arquitectura de software) es el conjunto de estructuras necesarias para razonar sobre un sistema.

La definición del texto es que la arquitectura de software de un sistema es el conjunto de estructuras necesarias para razonar sobre el sistema. Estas estructuras comprenden elementos de software, relaciones entre ellos y propiedades de ambos. En resumen, la arquitectura se trata de estructuras que habilitan el razonamiento.

Esta definición contrasta con otras que hablan de decisiones tempranas, importantes o principales: no todas las decisiones arquitectónicas son tempranas (especialmente en proyectos ágiles o en espiral), muchas decisiones tempranas no son arquitectónicas, y es difícil saber de antemano si una decisión es importante. Las estructuras, en cambio, son fáciles de identificar en el software y forman una herramienta poderosa para el diseño y el análisis.

El principio básico es que todo sistema de software se construye para satisfacer los objetivos de negocio de una organización, y la arquitectura es un puente entre esos objetivos (a menudo abstractos) y el sistema final (concreto). La complejidad de ese camino puede dominarse: las arquitecturas de software pueden diseñarse, analizarse y documentarse con técnicas conocidas que apoyan el logro de esos objetivos.
