# Use Case

> Descripción de cómo los actores pueden usar un sistema para lograr sus objetivos, frecuentemente usada para capturar los requisitos funcionales del sistema.

UML provee una notación gráfica para los diagramas de use case, pero no especifica cómo debe escribirse el texto. El diagrama UML de use case es una buena forma de dar una visión general de los actores y el comportamiento del sistema. La descripción textual debe incluir:
- Nombre del use case y una breve descripción.
- Actores primarios que lo inician.
- Actores secundarios que participan.
- Flujo de eventos.
- Flujos alternativos.
- Casos de no éxito.
