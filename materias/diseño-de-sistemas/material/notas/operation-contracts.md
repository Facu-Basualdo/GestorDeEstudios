# Operation Contracts

> Artefacto que complementa el texto del caso de uso para clarificar qué deben lograr los objetos de software en una operación del sistema; sus postcondiciones definen logros detallados.

Los contratos de operación pueden complementar el texto del caso de uso para clarificar qué deben lograr los objetos de software en una operación del sistema. Las postcondiciones definen logros detallados. Son una entrada al diseño de objetos.
