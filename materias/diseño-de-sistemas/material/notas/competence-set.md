# Competence Set

> Conjunto de estados en los que un programa es competente para operar.

El competence set de un programa es el conjunto de estados en los que es “competente” para operar. Por ejemplo, el estado en el que el denominador es cero está fuera del competence set de la mayoría de los programas de división. Cuando un componente lanza una excepción, está señalando que se descubrió fuera de su competence set: no sabe qué hacer y “tira la toalla”.
