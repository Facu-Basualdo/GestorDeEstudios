# Manage Deployed System

> Manage Deployed System es una categoría de tactics for deployability que agrupa estrategias para gestionar el sistema durante y después del despliegue.

La segunda categoría de tácticas de deployability se ocupa de gestionar el sistema mientras se está desplegando y una vez desplegado. Incluye las tácticas **manage service interactions**, **package dependencies** y **feature toggle**.
