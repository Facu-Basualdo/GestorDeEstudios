# HTTP

> HTTP es el protocolo más utilizado con REST, estandarizado por el World Wide Web Consortium (W3C), cuya forma básica es `<comando><URI>`.

Aunque no es el único protocolo que se puede usar con REST, HTTP es la elección más común. La forma básica del protocolo es `<comando><URI>`. Pueden incluirse otros parámetros, pero el corazón del protocolo es el comando y la URI. La tabla 15.1 lista los cinco comandos más importantes de HTTP y su relación con las operaciones CRUD (create, read, update, delete) de bases de datos.
