# Pair Programming

> El pair programming se caracteriza como un desk check continuo que fomenta la revisión constante mientras se crea el producto de trabajo.

En pair programming, dos personas trabajan juntas en una misma estación de trabajo para crear código. Esto proporciona resolución de problemas en tiempo real y aseguramiento de calidad continuo. Aunque algunos consideran que es redundante, la mejora en calidad puede justificar el uso de dos personas.
