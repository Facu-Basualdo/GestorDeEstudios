# Global Load Balancing

> Técnica para balancear la carga de los propios load balancers cuando se sobrecargan, haciendo que un mensaje pase por una jerarquía de load balancers antes de llegar a la instancia del servicio.

También se la llama "balancear la carga del load balancer". Se usa cuando el load balancer recibe más solicitudes de las que puede manejar.
