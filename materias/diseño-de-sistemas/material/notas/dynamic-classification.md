# Dynamic Classification

> Dynamic classification estima el consumo de energía a partir de condiciones transitorias como la carga de trabajo, cuando un modelo estático no es adecuado.

A diferencia de los modelos estáticos, los modelos dinámicos estiman el consumo de energía basándose en condiciones transitorias como el workload (carga de trabajo).

El modelo puede ser una tabla de búsqueda (lookup table), un modelo de regresión basado en datos recolectados en ejecuciones previas, o una simulación.
