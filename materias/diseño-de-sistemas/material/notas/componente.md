# Componente

> Un componente es un elemento físico en tiempo de ejecución, como servicios, puertos, clientes, servidores o filtros.

Cuando se habla de componentes no se habla de un componente lógico, sino de componentes físicos. Los componentes pueden ser servicios, puertos, clientes, servidores, filtros o cualquier tipo de elemento en tiempo de ejecución. En el ejemplo del material, el cliente se interpreta como un componente; como interesan las relaciones, el foco está en la dinámica.
