# Project Management Techniques

> Las buenas prácticas de gestión de proyectos (estimación realista, planificación basada en dependencias y gestión de riesgos) afectan positivamente la calidad del software.

El impacto de las malas decisiones de gestión en la calidad del software se ha discutido en la Sección 15.3.6. Las implicaciones son claras: si (1) un gerente de proyecto usa la estimación para verificar que las fechas de entrega son alcanzables, (2) las dependencias del cronograma se entienden y el equipo resiste la tentación de usar atajos, (3) la planificación de riesgos se realiza para que los problemas no generen caos, la calidad del software se verá afectada de manera positiva. Además, el plan del proyecto debe incluir técnicas explícitas para la calidad y la gestión del cambio.
