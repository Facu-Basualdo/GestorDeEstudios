# Propiedad Colectiva del Código

> Práctica de XP donde cualquier par de programadores puede mejorar cualquier código en cualquier momento.

Esto significa que todo el código tiene el beneficio de la atención de mucha gente, lo cual incrementa su calidad y reduce sus defectos.

La propiedad colectiva del código puede ser un problema si la gente trabaja a ciegas en código que no comprende. XP evita este problema a través de dos técnicas: las pruebas del programador para descubrir errores, y la programación de a pares, en este caso la mejor manera de trabajar con código no familiar es trabajar de a par con el experto.
