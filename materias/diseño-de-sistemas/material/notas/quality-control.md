# Quality Control

> El control de calidad comprende un conjunto de acciones de ingeniería de software que ayudan a garantizar que cada producto de trabajo cumpla con sus objetivos de calidad.

El control de calidad abarca un conjunto de acciones de ingeniería de software que ayudan a garantizar que cada producto de trabajo cumpla con sus objetivos de calidad. Los modelos se revisan para asegurar que sean completos y consistentes. El código puede ser inspeccionado para descubrir y corregir errores antes de que comiencen las pruebas. Se aplica una serie de pasos de prueba para descubrir errores en la lógica de procesamiento, manipulación de datos y comunicación de interfaces. Una combinación de medición y retroalimentación permite al equipo de software ajustar el proceso cuando alguno de estos productos de trabajo no cumple con los objetivos de calidad.
