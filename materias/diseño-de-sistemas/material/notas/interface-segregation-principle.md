# Interface Segregation Principle

> Patrón que permite convertir unas interfaces en otras, de modo que se transformen en pequeñas interfaces mejores encapsuladas.

- Permite convertir unas interfaces en otras, cosa de que pueda transformar en pequeñas interfaces mejores encapsuladas.
- Evita errores inesperados o independencias innecesarias.
- Además se reutiliza código de forma mucho más inteligente.
