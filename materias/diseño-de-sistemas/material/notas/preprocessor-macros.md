# Preprocessor Macros

> Macros de preprocesador que, al activarse, se expanden a código que reporta el estado o activa sondas que devuelven o muestran información.

Cuando se activan, también pueden devolver el control a una consola de pruebas. Son una técnica disponible para reemplazar un componente por una versión que facilita la prueba.
