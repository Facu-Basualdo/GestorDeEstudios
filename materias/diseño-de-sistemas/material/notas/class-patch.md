# Class Patch

> Tipo de actualización aplicable a objetivos que ejecutan código orientado a objetos, donde las definiciones de clase incluyen un mecanismo de backdoor que permite agregar datos y funciones miembro en tiempo de ejecución.

Se utiliza típicamente para entregar correcciones de errores, junto con el function patch, mientras que el hitless ISSU se usa para nuevas funcionalidades.
