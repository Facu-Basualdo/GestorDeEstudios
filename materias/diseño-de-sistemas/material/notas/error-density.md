# Error Density

> Error density is the number of errors found per unit of work product reviewed, calculated as total errors divided by work product size.

Error density = Errtot / WPS. For example, if a requirements model has 22 errors and 32 pages, error density is 0.68 errors per page. This metric can be used to estimate the number of errors to be found in a new document before review.
