# Responsibility-Driven Design

> Enfoque de diseño de software que piensa los objetos en términos de responsabilidades, roles y colaboraciones.

En RDD, los objetos de software tienen responsabilidades, una abstracción de lo que hacen. Las responsabilidades se asignan a clases de objetos durante el diseño de objetos. RDD también incluye la idea de colaboración: las responsabilidades se implementan mediante métodos que actúan solos o colaboran con otros métodos y objetos.

RDD es una metáfora general para pensar el diseño de software OO: los objetos de software son similares a personas con responsabilidades que colaboran con otras personas para hacer el trabajo. Esto lleva a ver un diseño OO como una comunidad de objetos responsables que colaboran.

GRASP nombra y describe algunos principios básicos para asignar responsabilidades, por lo que es útil para apoyar RDD.
