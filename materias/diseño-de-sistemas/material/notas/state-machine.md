# State Machine

> Formalismo usado por muchas notaciones comprehensivas que representa el comportamiento de los elementos de la arquitectura, donde cada estado es una abstracción de todas las historias posibles que podrían llevar a ese estado.

Los lenguajes de state machine permiten complementar una descripción estructural de los elementos del sistema con restricciones sobre interacciones y reacciones temporizadas a estímulos tanto internos como del entorno. Las state machines son la base de las notaciones comprehensivas.
