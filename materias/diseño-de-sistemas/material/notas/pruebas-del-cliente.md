# Pruebas del Cliente

> Práctica de XP donde el Cliente define pruebas automatizadas de aceptación para cada característica deseada.

Como parte de la presentación de cada característica deseada, el Cliente define una o más pruebas automatizadas de aceptación para determinar si la característica funciona. El equipo utiliza estas pruebas para demostrarse a sí mismo y al Cliente que la característica está implementada correctamente. La automatización de la prueba es importante, porque bajo la presión del tiempo, las pruebas manuales son dejadas de lado.

El equipo XP trata las pruebas del Cliente de la misma forma que las pruebas de los programadores: una vez que la prueba corre aceptablemente, el equipo la debe continuar ejecutándola correctamente a posteriori.
