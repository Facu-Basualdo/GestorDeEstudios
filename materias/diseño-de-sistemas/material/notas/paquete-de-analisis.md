# Paquete de análisis

> Agrupación de clases de análisis que sigue el criterio de vincular las clases de un caso de uso o de casos de uso muy vinculados.

Dentro del sistema de análisis puede haber paquetes, y los paquetes pueden contener otros paquetes.
El criterio de agrupamiento es vincular las clases de un CU o de CU muy vinculados.
Esta capa de paquetes es la que estaría más arriba de todos.
