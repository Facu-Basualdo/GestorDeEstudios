# Software Engineering Methods

> La aplicación de métodos de ingeniería de software apropiados (análisis y diseño) aumenta la probabilidad de crear software de alta calidad.

Si esperas construir software de alta calidad, debes entender el problema a resolver. También debes ser capaz de crear un diseño que se ajuste al problema y que al mismo tiempo exhiba características que conduzcan a software que presente las dimensiones y factores de calidad discutidos en la Sección 15.2. En la Parte Dos de este libro, presentamos una amplia gama de conceptos y métodos que pueden conducir a una comprensión razonablemente completa del problema y un diseño integral que establece una base sólida para la actividad de construcción. Si aplicas esos conceptos y adoptas métodos apropiados de análisis y diseño, la probabilidad de crear software de alta calidad aumentará sustancialmente.
