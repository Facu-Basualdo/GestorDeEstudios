# Caso de prueba

> Un caso de prueba define exactamente qué se va a probar, indicando qué caso de uso se prueba y qué desencadena cada paso de ese caso de uso.

Permite saber qué vamos a probar y es una forma de probar el sistema. Hay que definir cuáles son los requerimientos, entonces se define el CU. Hay una relación de traza directa entre el caso de prueba y el CU.

Puede haber muchos casos de prueba para el mismo CU. Se aplican conceptos de caja negra y caja blanca al caso de prueba. Un caso de prueba incluye ejemplo, entrada, resultado y condiciones; las condiciones no son ni PRE ni POST, sino condiciones durante la ejecución, que aseguran que no haya otras ejecuciones.
