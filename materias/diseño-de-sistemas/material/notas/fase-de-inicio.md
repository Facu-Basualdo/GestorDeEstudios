# Fase de inicio

> Es la primera fase del ciclo, donde se define si se completa mediante hitos y se identifica la factibilidad del proyecto.

- Uno de los objetivos es identificar la factibilidad del proyecto.
- El hecho de que sea iterativo e incremental hace que sea menos riesgoso.
- Se genera una vista de características y un boceto de arquitectura.
- El modelo de negocio sirve para mencionar en alto nivel el dominio del problema; un caso especial de este es el modelo de dominio, modelado a través de clases conceptuales.
- Los casos de uso son formas de modelar procesos de negocios.
