# Use Case Realization

> En el UP, nombre que recibe el diseño orientado a objetos que realiza (implementa) los casos de uso.

El texto del caso de uso define el comportamiento visible que los objetos de software deben soportar; los objetos se diseñan para 'realizar' (implementar) los casos de uso. En el UP, a este diseño orientado a objetos se lo llama *use case realization*.
