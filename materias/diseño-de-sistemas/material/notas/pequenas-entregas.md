# Pequeñas Entregas

> Práctica de XP donde los equipos entregan software ejecutable probado al final de cada iteración.

El software es de valor para el negocio elegido por el cliente. El Cliente puede utilizar este software para cualquier propósito, ya sea de evaluación o aún liberarlo a los usuarios finales (recomendado). El aspecto más importante es que el software es visible, y se entrega al Cliente al final de cada iteración.
