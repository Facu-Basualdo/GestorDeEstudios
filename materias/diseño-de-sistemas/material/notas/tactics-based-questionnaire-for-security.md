# Tactics-Based Questionnaire for Security

> Cuestionario basado en las tácticas de seguridad para obtener una visión general de las decisiones arquitectónicas que soportan la seguridad.

El analista hace cada pregunta inspirada en las tácticas de seguridad y registra las respuestas en la tabla. Las respuestas pueden convertirse en el foco de actividades posteriores: investigación de documentación, análisis de código u otros artefactos, ingeniería inversa de código, etc.
