# Uses and Audiences for Architecture Documentation

> La documentación de arquitectura tiene cuatro usos fundamentales: educación, comunicación entre stakeholders, base para el análisis y construcción, y base para la investigación de incidentes.

La documentación de arquitectura debe ser suficientemente transparente para que la entiendan rápido los empleados nuevos, suficientemente concreta para servir de blueprint para la construcción o la forensia, y con suficiente información para servir de base al análisis. Tiene cuatro usos:

1. **Educación**: introduce el sistema a personas nuevas: miembros del equipo, analistas externos, un arquitecto nuevo o el cliente que ve la solución por primera vez.
2. **Comunicación entre stakeholders**: es el vehículo principal de comunicación; por ejemplo, el futuro arquitecto la usa como repositorio de decisiones de diseño.
3. **Base para análisis y construcción**: indica a los implementadores qué módulos construir y cómo se conectan, y contiene la información necesaria para evaluar atributos como seguridad, performance, usabilidad, disponibilidad y modificabilidad.
4. **Base para forensia**: cuando ocurre un incidente, permite rastrear la causa inmediata y subyacente mediante el flujo de control y las especificaciones de interfaces.

Para que siga dando valor, la documentación debe mantenerse al día.
