# Implementation Structure

> La implementation structure (estructura de implementación) muestra cómo los elementos de software (usualmente módulos) se mapean a las estructuras de archivos en los entornos de desarrollo, integración, prueba o control de configuración.

Esta estructura es crítica para la gestión de las actividades de desarrollo y de los procesos de build.
