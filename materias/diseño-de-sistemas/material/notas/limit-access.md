# Limit Access

> Táctica que limita el acceso a los recursos informáticos restringiendo los puntos de acceso o el tipo de tráfico permitido.

Ambos tipos de límites minimizan la superficie de ataque del sistema. Por ejemplo, una zona desmilitarizada (DMZ) se usa cuando una organización quiere permitir a usuarios externos acceder a ciertos servicios pero no a otros. La DMZ se ubica entre Internet y una intranet, protegida por dos firewalls; el firewall interno es un punto único de acceso a la intranet.
