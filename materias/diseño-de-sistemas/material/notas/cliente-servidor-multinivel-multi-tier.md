# Cliente-Servidor multinivel (Multi-Tier)

> Arquitectura cliente-servidor en la que la capa del servidor se sigue dividiendo en varios niveles, manteniendo el esquema de cliente y servidor.

La clave de los sistemas distribuidos, además de compartir datos, es compartir recursos. La idea era tener muchos clientes que se conecten a una misma base de datos. Tier se suele asociar a capa física y layer a capa lógica. Mientras más capas se añaden, más se distinguen los elementos que generan datos y los que los presentan.
