# Componentes SQA

> El SQA integra y supervisa múltiples áreas: definición del proceso SQA, revisiones y pruebas, métodos y herramientas, y control de cambios.

- Definición del proceso SQA.
- Revisiones y pruebas (tareas y específicas).
- Revisión y prueba unitaria: la prueba necesita código ejecutable; la revisión no necesariamente.
- Métodos y herramientas.
- Control de cambios (productos de trabajo).
- El control de cambios es importante para tener trazabilidad y poder detectar dónde hay errores.
