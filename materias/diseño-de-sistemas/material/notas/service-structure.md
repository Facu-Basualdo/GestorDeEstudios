# Service Structure

> La service structure (estructura de servicios) tiene como unidades a servicios que interoperan a través de un mecanismo de coordinación, como mensajes.

Es una C&C structure importante para diseñar un sistema compuesto por componentes que pueden haber sido desarrollados de manera independiente entre sí.
