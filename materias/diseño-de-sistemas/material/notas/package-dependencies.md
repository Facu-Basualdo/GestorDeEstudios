# Package Dependencies

> Package dependencies es una táctica de deployability que empaqueta un elemento junto con sus dependencias para que se desplieguen juntos y las versiones sean consistentes.

Las dependencias pueden incluir bibliotecas, versiones de sistema operativo y contenedores de utilidades (por ejemplo, sidecar, service mesh). Tres medios de empaquetar dependencias son contenedores, pods o máquinas virtuales.
