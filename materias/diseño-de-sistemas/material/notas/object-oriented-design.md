# Object-Oriented Design (OOD)

> Disciplina de diseño que decide qué métodos pertenecen a qué clases y cómo interactúan los objetos para cumplir los requisitos, gobernada por un gran conjunto de principios suaves y patrones.

El diseño orientado a objetos a veces se enseña como: después de identificar los requisitos y crear un modelo de dominio, agregar métodos a las clases apropiadas y definir el envío de mensajes entre los objetos para cumplir los requisitos. Ese consejo no alcanza: dominar OOD involucra un gran conjunto de principios suaves, con muchos grados de libertad. Los patrones se pueden nombrar, explicar y aplicar.
