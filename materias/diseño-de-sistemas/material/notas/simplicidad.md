# Simplicidad

> Valor de Agile Modeling que destaca la importancia de los modelos para simplificar el software y el proceso de desarrollo.

Es importante que los desarrolladores comprendan que los modelos son críticos para simplificar tanto el software como el proceso de desarrollo de software. Es más sencillo explorar una idea dibujando un diagrama que escribiendo centenas de líneas de código.
