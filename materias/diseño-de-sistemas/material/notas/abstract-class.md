# Abstract Class

> Una clase abstracta tiene como propósito principal definir una interfaz común para sus subclases.

Una clase abstracta difiere parte o toda su implementación a operaciones definidas en subclases; por lo tanto, no puede ser instanciada. Las operaciones que una clase abstracta declara pero no implementa se llaman operaciones abstractas. Las clases que no son abstractas se llaman clases concretas.
