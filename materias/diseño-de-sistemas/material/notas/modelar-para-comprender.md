# Modelar para Comprender

> Usar el modelado para comprender el espacio del problema, identificar y analizar requerimientos, y comparar alternativas de diseño.

La aplicación más importante del modelado es para comprender el espacio del problema, para identificar y analizar requerimientos para el sistema, o para comparar alternativas de diseño potenciales, para identificar potencialmente la solución mas sencilla que cubra los requerimientos.
