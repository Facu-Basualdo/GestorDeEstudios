# Software Quality Goals, Attributes, and Metrics

> Marco para evaluar la calidad del software mediante objetivos (requirements quality, design quality, code quality, quality control effectiveness) que se miden a través de atributos y métricas específicas.

Los objetivos de calidad son: calidad de requisitos, calidad de diseño, calidad de código y efectividad del control de calidad. Para cada objetivo se definen atributos indicadores y métricas. Por ejemplo, para la calidad de requisitos, los atributos son ambigüedad, completitud, comprensibilidad, volatilidad, trazabilidad y claridad del modelo, y sus métricas incluyen número de modificadores ambiguos, TBA/TBD, secciones/subs secciones, cambios por requisito, requisitos no trazables, modelos UML, etc. Para calidad de diseño, atributos como integridad arquitectónica, completitud de componentes, complejidad, adecuación del diseño, patrones. Para calidad de código, atributos como complejidad (medida por complejidad ciclomática), mantenibilidad, comprensibilidad, reusabilidad. Para efectividad del control de calidad, atributos como asignación de recursos, tasa de finalización, efectividad de revisiones y pruebas. (Ver Tabla 17.1)
