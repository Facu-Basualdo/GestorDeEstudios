# Tácticas

> Forma o decisión de diseño que interactúa o moldea el sistema y define cómo el sistema responde a un estímulo.

Son formas o decisiones de diseño que interactúan o moldean el sistema y definen cómo este responde a un estímulo. No se inventan: plasman las buenas prácticas de los arquitectos.

Hay tres razones para centrarse en la táctica:
1. Los arquitectos frecuentemente necesitan modificar y adaptar los patrones a su contexto particular; las tácticas proporcionan un medio sistemático para ampliar un patrón existente y subsanar todas sus deficiencias.
2. Si no existe un patrón para lograr el objetivo de diseño, las tácticas permiten construir un fragmento de diseño a partir de “principios fundamentales”.
3. Las tácticas ofrecen una forma de sistematizar el diseño y el análisis, dentro de ciertas limitaciones.
