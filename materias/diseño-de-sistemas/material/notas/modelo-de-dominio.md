# Modelo de dominio

> El modelo de dominio describe cuáles son las clases conceptuales que maneja el dominio, generalmente contempladas por el sistema.

- Es un caso especial del modelo de negocio y se modela a través de clases conceptuales.
- Puede pasar, aunque es raro, que alguna clase conceptual no sea contemplada por el sistema.
- Es fundamental para saber dónde va a funcionar el sistema.
- Por defecto habla de la situación actual, previa a la informatización de ese dominio.
- Puede ocurrir que haya que modelar cómo quedaría el sistema cuando no quede otra.
