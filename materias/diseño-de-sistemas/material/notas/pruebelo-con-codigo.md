# Pruébelo con código

> Un modelo debe reflejar con precisión un aspecto del sistema, pero para determinar si funciona debe probarse con código.

Un modelo es una abstracción que debe reflejar con precisión un aspecto del sistema en construcción, pero para determinar si el mismo funcionará debe probarse con código. Por ejemplo, si se encuentra desarrollando un diagrama de secuencia que modela un proceso de negocio, escriba el código de prueba, el código de los objetos del negocio, y asegúrese de que funciona correctamente.
