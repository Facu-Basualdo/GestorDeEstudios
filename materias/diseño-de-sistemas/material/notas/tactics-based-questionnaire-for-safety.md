# Tactics-Based Questionnaire for Safety

> Cuestionario basado en tácticas de seguridad que el analista utiliza para obtener una visión general de las decisiones arquitectónicas que soportan la seguridad, registrando las respuestas en una tabla.

Se construye a partir de las tácticas descritas en la Sección 10.2. El analista hace cada pregunta y anota las respuestas en la tabla. Las respuestas orientan actividades posteriores como la investigación de documentación, el análisis de código u otros artefactos, y la ingeniería inversa del código.

Antes de comenzar, se debe evaluar si el proyecto bajo revisión ha realizado un hazard analysis o un FTA para identificar qué constituye un estado inseguro en el sistema. Sin este análisis, el diseño para la seguridad probablemente sea menos efectivo.
