# Use Case Text

> Texto del caso de uso que define el comportamiento visible que los objetos de software deben soportar.

El texto del caso de uso define el comportamiento visible que los objetos de software deben soportar. Es una entrada al diseño de objetos; en el UP, el diseño que lo realiza se llama *use case realization*.
