# Evaluar prueba

> Actividad del proceso de pruebas, realizada por el Ingeniero de pruebas, que produce la evaluación de prueba para una iteración a partir del plan de prueba, el modelo de prueba y los defectos.

El Ingeniero de pruebas es el actor responsable.

- Entradas: Plan de prueba, Modelo de prueba, Defecto.
- Resultado: Evaluación de prueba (para una iteración).
