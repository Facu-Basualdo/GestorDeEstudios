# Múltiples Modelos

> Potencialmente necesitará desarrollar múltiples modelos para describir diferentes aspectos del software.

Potencialmente necesitará desarrollar múltiples modelos para desarrollar el software ya que cada modelo describe un aspecto simple del mismo. ¿Qué modelos son requeridos para modelar una aplicación moderna? Considerando la complejidad del software actual, se necesita un amplio rango de técnicas en su caja de herramientas de modelado para ser efectivo. Un punto importante es que no necesita desarrollar la totalidad de dichos modelos para un sistema dado, pero dependiendo de la naturaleza del software que esté desarrollando, necesitará un subconjunto de los mismos. Diferentes sistemas, diferentes subconjuntos. Normalmente hay ciertos modelos que se utilizarán más a menudo que otros.
