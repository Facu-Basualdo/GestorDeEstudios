# Vista de Desarrollo

> La vista de desarrollo muestra cómo el software se descompone para el desarrollo, en componentes implementados por un desarrollador o un grupo de ellos.

- Es una de las cuatro perspectivas fundamentales del modelo **Vistas 4+1**.
- Muestra cómo el software se descompone para el desarrollo, es decir, en **componentes** implementados por un desarrollador o un grupo de ellos.
- Es útil para **programadores** y **managers**.
