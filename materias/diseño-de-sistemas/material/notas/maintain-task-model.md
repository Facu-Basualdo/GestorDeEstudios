# Maintain Task Model

> Maintain Task Model es una táctica de soporte a la iniciativa del sistema que mantiene un modelo de la tarea para determinar el contexto y predecir lo que el usuario intenta hacer.

El modelo de tarea se usa para determinar el contexto, de modo que el sistema pueda tener una idea de lo que el usuario está intentando hacer y brindar asistencia. Por ejemplo, muchos buscadores ofrecen capacidades de autocompletado predictivo (type-ahead) y muchos clientes de correo ofrecen corrección ortográfica; ambas funciones se basan en modelos de tarea.
