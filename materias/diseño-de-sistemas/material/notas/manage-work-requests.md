# Manage Work Requests

> Táctica de control de demanda que reduce la cantidad de solicitudes de trabajo que entran al sistema.

Una forma de reducir trabajo es reducir el número de solicitudes que recibe el sistema. Las maneras de hacerlo incluyen Manage Event Arrival y Manage Sampling Rate.
