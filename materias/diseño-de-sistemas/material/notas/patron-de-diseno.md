# Patrón de diseño

> Un patrón describe un problema que ocurre una y otra vez en el entorno y ofrece una solución base para abordarlo.

- Es un modelo que sirve de muestra para otra cosa igual, pero no se da una receta: se describen las características básicas para abordar el problema.
- En síntesis, el patrón es un par problema-solución: para cada problema se aplica una solución base.
- Las soluciones no siempre salen idénticas a la original, y cada una vale para un contexto (entorno) particular.
- Se manejan de la más genérica a la más específica en el campo.
