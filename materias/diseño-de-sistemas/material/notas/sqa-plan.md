# SQA Plan

> The SQA plan provides a road map for instituting software quality assurance, developed by the SQA group or software team, serving as a template for SQA activities for each software project.

The IEEE standard [IEE17] recommends the plan structure: (1) purpose and scope, (2) description of software engineering work products within SQA purview, (3) applicable standards and practices, (4) SQA actions and tasks (reviews and audits) and their placement, (5) tools and methods, (6) software configuration management procedures, (7) methods for assembling, safeguarding, and maintaining SQA records, (8) organizational roles and responsibilities relative to product quality.
