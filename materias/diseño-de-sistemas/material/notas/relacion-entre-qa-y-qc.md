# Relación entre QA y QC

> QA y QC se relacionan con el control de calidad: si el producto cumplió con los estándares es control de calidad (QC), y si satisface las necesidades del usuario es validación.

- Verificación y validación son muy cercanas al control de calidad.
- Vienen de diferentes orígenes; el aseguramiento de calidad viene de las fábricas (es otro tipo de industria).
- Si el producto cumple los estándares, es control de calidad.
- Si el producto satisface las necesidades del usuario, es validación.
