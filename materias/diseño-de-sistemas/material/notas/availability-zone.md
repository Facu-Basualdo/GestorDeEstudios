# Availability Zone

> Una availability zone es un agrupamiento de data centers dentro de una cloud region, con una probabilidad extremadamente baja de que fallen simultáneamente los data centers de dos zonas distintas.

Una cloud region tiene muchos data centers distribuidos físicamente, con diferentes fuentes de energía eléctrica y conectividad a Internet. Los data centers dentro de una región se agrupan en availability zones. A veces la zona se elige automáticamente, pero a menudo conviene elegirla manualmente por disponibilidad y continuidad del negocio.
