# Vista Física

> La vista física muestra el hardware y el software y cómo están distribuidos para formar el sistema.

- Es una de las cuatro perspectivas fundamentales del modelo **Vistas 4+1**.
- Muestra el **hardware** y el **software** y cómo están distribuidos para formar el sistema.
- Es útil para los **ingenieros en sistemas** que planean un despliegue del sistema.
- En los apuntes de clase se la menciona como 'vista de despliegue': cómo van a distribuir...
