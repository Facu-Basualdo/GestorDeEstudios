# Ciclo - Fase - Iteración

> Es la estructura del ciclo de vida del PU: el desarrollo está compuesto por varios ciclos, cada ciclo produce una versión del producto y se divide en fases que contienen iteraciones.

El ciclo de software está compuesto por varios ciclos; en cada uno hay una versión del producto. Dentro de cada fase existen iteraciones, por eso el proceso es iterativo e incremental. De un proyecto de software se obtiene como resultado un producto, que en el PU abarca más que el software ejecutable: incluye el resto de los modelos. En la primera fase hay una release que no es muy ejecutable, pero igual se la considera release. En la fase de transición no se hace mantenimiento, pero se realizan correcciones para que el producto sea utilizable. El resultado de cada iteración son versiones internas o incrementos: no se entregan al cliente, pero le permiten al equipo ver el progreso, probar y obtener feedback.
