# Requisitos no funcionales

> Son requisitos que no son específicos de un caso de uso y se aplican de forma general; se registran en la lista de requisitos suplementarios.

- Los casos de uso no son una herramienta tan útil para capturarlos.
- En la lista de requisitos suplementarios va la lista de requisitos no funcionales que no son específicos de un caso de uso.
