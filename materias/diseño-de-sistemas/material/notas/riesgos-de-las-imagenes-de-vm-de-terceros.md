# Riesgos de las imágenes de VM de terceros

> Problemas que pueden surgir al descargar y ejecutar una VM image que no fue creada por la propia organización.

- No se pueden controlar las versiones del sistema operativo y del software.
- La imagen puede tener software con vulnerabilidades o que no está configurado de forma segura; incluso puede incluir malware.
- Esto aplica a imágenes que uno o su organización no crearon.
