# Tactics-Based Questionnaire for Performance

> Cuestionario basado en las tácticas de performance para relevar y registrar las decisiones arquitectónicas que soportan la performance.

A partir de las tácticas de la Sección 9.2, se crea un conjunto de preguntas inspiradas en tácticas, presentado en la Tabla 9.2. Para obtener una visión general de las decisiones arquitectónicas tomadas para soportar la performance, el analista hace cada pregunta y registra las respuestas en la tabla. Las respuestas pueden convertirse en el foco de actividades posteriores: investigación de documentación, análisis de código u otros artefactos, reverse engineering de código, etc.
