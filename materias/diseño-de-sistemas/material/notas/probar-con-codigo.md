# Probar con Código

> Probar un modelo con código para verificar que funcione correctamente.

Un modelo es una abstracción que debe reflejar con precisión un aspecto del sistema en construcción, pero para determinar si el mismo funcionará debe probarse con código. Por ejemplo, si se encuentra desarrollando un diagrama de secuencia que modela un proceso de negocio, escriba el código de prueba, el código de los objetos del negocio, y asegúrese de que funciona correctamente. Es una práctica central de Agile Modeling que se enmarca en la categoría 'Validación'.
