# Evaluación de calidad

> La evaluación de calidad combina dos enfoques complementarios: el cualitativo y el cuantitativo.

- Cualitativo: se prefiere porque hay cosas difíciles de medir con números.
- Cuantitativo: usa métricas indirectas, porque la calidad no se puede medir directamente.
- Ningún indicador va a ser perfecto; se puede usar una combinación de métricas.
