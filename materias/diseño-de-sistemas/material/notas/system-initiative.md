# System Initiative

> La system initiative describe el caso en que el sistema toma la iniciativa en la interacción.

Por ejemplo, durante la cancelación de un comando, el sistema puede mostrar un indicador de progreso (system initiative). El término se usa para describir cuál de los dos, humano o computadora, toma la iniciativa en realizar ciertas acciones y cómo procede la interacción.
