# XML Schema

> Documento XML que define un lenguaje personalizado para describir datos, especificando etiquetas, tipos de datos y restricciones estructurales.

El esquema es en sí mismo un documento XML. Permite al arquitecto especificar una estructura de información rica. Los documentos XML pueden validarse contra su esquema para comprobar que cumplen la estructura definida; esto previene fallos causados por documentos malformados y elimina la necesidad de algunos tipos de verificación de errores por parte del código que lee y procesa el documento.
