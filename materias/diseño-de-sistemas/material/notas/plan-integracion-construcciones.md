# Plan de Integración de Construcciones

> Artefacto que define, para cada construcción, la funcionalidad y los casos de uso a implementar, y decide qué es lo que se va a implementar.

Para cada construcción se va a tener la funcionalidad y los casos de uso que se van a implementar. Es muy importante porque decide qué se va a implementar. Cada build puede terminar bien o mal: cuando termina bien, resulta en una pequeña integración; si resulta mal, termina en un error de prueba. Tanto la construcción como el error son artefactos; el error se va a usar como prueba. Hay ventajas de hacerlo de manera incremental.
