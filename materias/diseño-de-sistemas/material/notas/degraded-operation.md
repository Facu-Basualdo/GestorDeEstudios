# Degraded Operation

> La operación degradada es un modo en el que un sistema debe entrar cuando los sensores fallan o se vuelven ilegibles.

Por ejemplo, si no hay lecturas de GPS en túneles, el sistema puede usar técnicas de dead reckoning para estimar la ubicación. La representación del entorno y el enfoque apropiado para la operación degradada son específicos del dominio.
