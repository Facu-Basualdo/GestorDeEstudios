# Caso de uso de sistema

> Un caso de uso de sistema captura requisitos funcionales y se deriva de los casos de uso de negocio.

- Está pensado para capturar requisitos funcionales.
- No es una herramienta tan útil para capturar requisitos no funcionales.
- Puede servir como punto de concentración o agrupamiento.
- La especificación de un CU de qué hace se realiza con el diagrama de actividades.
