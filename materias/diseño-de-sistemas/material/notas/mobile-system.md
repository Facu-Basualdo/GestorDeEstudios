# Mobile System

> Un mobile system es un sistema que tiene la capacidad de estar en movimiento mientras continúa entregando parte o toda su funcionalidad.

Ejemplos de mobile systems: teléfonos, trenes, aviones, automóviles, barcos, satélites, dispositivos de entretenimiento y cómputo personal, y sistemas robóticos (autónomos o no). Tienen en común que no tienen una conexión permanente a una fuente de energía continua y abundante. En el capítulo se enfocan cinco características:
1. **Energy**
2. **Network Connectivity**
3. **Sensors and Actuators**
4. **Resources**
5. **Life Cycle**
