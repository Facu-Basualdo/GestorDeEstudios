# Sensitivity Point

> Un punto de sensibilidad es una decisión arquitectónica que tiene un efecto marcado en la respuesta de un atributo de calidad.

Junto con los puntos de tradeoff, forman parte de las salidas del ATAM. Se identifican para cada escenario de atributo de calidad examinado.
