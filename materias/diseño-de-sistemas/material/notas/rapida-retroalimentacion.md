# Rápida Retroalimentación

> El tiempo entre la acción y la retroalimentación sobre la acción es crítico.

El tiempo entre la acción y la retroalimentación sobre la acción es crítico. Trabajando con otra gente en un modelo, particularmente trabajando con una tecnología de modelado compartida (tales como pizarrones, tarjetas CRC, o elementos mas simples como notas autoadhesivas) se obtiene una retroalimentación casi instantánea sobre sus ideas. Trabajando estrechamente con sus clientes, para comprender sus requerimientos, para analizar dichos requerimientos, o para desarrollar la interfase de usuario que cubra sus expectativas, provee oportunidades de rápida retroalimentación.
