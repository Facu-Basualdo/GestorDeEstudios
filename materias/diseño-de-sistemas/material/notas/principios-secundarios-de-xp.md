# Principios secundarios de XP

> Los principios secundarios de XP son la pequeña inversión inicial, la adaptación local y el viaje liviano.

Pequeña inversión inicial: los proyectos con mucho presupuesto inicial se desenfocan; es mejor arrancar con un presupuesto acotado al principio para poder enfocarse. Adaptación local: cambia para cada proyecto. Viaje liviano: mantener solo los artefactos mínimos e indispensables; el único artefacto necesario es el código y, para muchos proyectos, esa es la documentación.
