# Modelo

> Un modelo es autocontenido: tiene la información suficiente para representarse por sí solo, aunque tenga relaciones de traza con otros modelos.

- Los modelos tienen relaciones de traza entre sí, pero no necesitan la información de otro para poder entender/comprender el que se está leyendo.
- Gracias a esas relaciones de traza, sí se depende del modelo anterior para poder realizar el siguiente.
- Una relación de traza no añade información a los elementos involucrados: simplemente los une. Si añadiera información, no podríamos decir que los modelos son autocontenidos.
