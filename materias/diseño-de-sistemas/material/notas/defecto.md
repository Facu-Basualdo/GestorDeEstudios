# Defecto

> Un defecto es un problema del sistema que hay que controlar y resolver, representado como un artefacto para saber si se solucionó o no.

Puede ser algo escrito, por ejemplo un síntoma de un fallo de software o un problema descubierto en una revisión. Al ejecutar la prueba, si existiesen, aparece un conjunto de defectos.
