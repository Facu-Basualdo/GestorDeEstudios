# Architectural Backlog

> Lista de tareas pendientes que deben realizarse como parte del proceso de diseño de la arquitectura.

Inicialmente se puebla con los drivers, pero también pueden incluirse otras actividades que apoyen el diseño:
- creación de un prototipo para probar una tecnología o abordar un riesgo de QA,
- exploración y comprensión de activos existentes (posiblemente con ingeniería inversa),
- issues descubiertos en una revisión de las decisiones de diseño.

Se pueden agregar más ítems a medida que se toman decisiones. Por ejemplo, si se elige una arquitectura de referencia y se descubre que no provee gestión de sesión, esa preocupación se agrega al backlog.
