# Achieving Software Quality

> La calidad del software se logra mediante la aplicación de métodos de ingeniería de software, técnicas de gestión de proyectos, acciones de control de calidad y aseguramiento de la calidad.

La calidad del software no aparece simplemente. Es el resultado de una buena gestión de proyectos y una sólida práctica de ingeniería de software. La gestión y la práctica se aplican en el contexto de cuatro actividades amplias que ayudan a un equipo de software a lograr una alta calidad del software: métodos de ingeniería de software, técnicas de gestión de proyectos, acciones de control de calidad y aseguramiento de la calidad del software.
