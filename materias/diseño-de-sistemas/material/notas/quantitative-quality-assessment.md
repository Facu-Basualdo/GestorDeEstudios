# Quantitative Quality Assessment

> La evaluación cuantitativa de calidad utiliza métricas de software para detectar defectos de diseño como alto acoplamiento o complejidad innecesaria.

Se pueden detectar varios defectos de diseño mediante métricas de software. El proceso consiste en encontrar fragmentos de código que sugieran la presencia de alto acoplamiento o niveles innecesarios de complejidad. Los atributos internos del código pueden describirse cuantitativamente usando métricas. Cuando los valores de las métricas caen fuera del rango aceptable, señala la existencia de un problema de calidad que debe investigarse. Las métricas representan medidas indirectas; nunca medimos realmente la calidad sino alguna manifestación de ella. El factor complicado es la relación precisa entre la variable medida y la calidad del software.
