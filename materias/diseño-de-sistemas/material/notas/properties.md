# Properties

> Las properties son la metadata de una interfaz, como derechos de acceso, unidades de medida o supuestos de formato, que pueden influir en el comportamiento de las operaciones.

Otro nombre para esta metadata es properties. Los valores de las properties pueden influir en el comportamiento de las operaciones y también afectan el comportamiento del elemento según su estado. Las interfaces complejas de elementos que son stateful y activos combinan operaciones, eventos y properties.
