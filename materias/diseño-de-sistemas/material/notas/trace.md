# Trace

> Secuencia de actividades o interacciones que describe la respuesta del sistema a un estímulo específico cuando el sistema se encuentra en un estado específico.

Un trace describe una secuencia de actividades o interacciones entre elementos estructurales del sistema. Aunque se podrían describir todos los traces posibles para generar el equivalente a un modelo de comportamiento comprehensivo, la documentación orientada a traces no busca hacerlo. Las notaciones para documentar traces incluyen use cases, sequence diagrams, communication diagrams y activity diagrams.
