# Exception/Error-Handling View

> Una exception/error-handling view ayuda a iluminar y llamar la atención sobre los mecanismos de reporte y resolución de errores.

Muestra cómo los componentes detectan, reportan y resuelven fallas o errores. Ayuda al arquitecto a identificar las fuentes de errores y especificar las acciones correctivas apropiadas para cada una. Finalmente, facilita el análisis de causa raíz en esos casos.
