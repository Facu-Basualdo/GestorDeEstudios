# Qualitative Quality Assessment

> La evaluación cualitativa de calidad evalúa factores de calidad mediante listas de verificación y preguntas dirigidas a atributos específicos del software.

Se pueden desarrollar características de calidad y preguntas asociadas que indaguen el grado de satisfacción de cada factor. Por ejemplo, para la usabilidad (según ISO 25010) se pueden evaluar subcaracterísticas como adecuación, capacidad de aprendizaje, operabilidad, protección contra errores, estética y accesibilidad. Se puede crear un cuestionario para usuarios y un conjunto de tareas estructuradas, observando a los usuarios mientras las realizan. Las preguntas típicas incluyen: ¿Qué tan rápido pueden los usuarios determinar si el software es adecuado para su tarea? ¿Cuánto tiempo les lleva aprender a usar las funciones? ¿Pueden recordar cómo usarlas sin reaprender? ¿Cuánto tiempo toman para completar tareas? ¿El sistema previene errores? ¿Permite deshacer operaciones? ¿La apariencia es satisfactoria? ¿La interfaz cumple con las reglas de oro y la accesibilidad? Si la mayoría de las respuestas son afirmativas, es probable que la interfaz tenga alta calidad.
