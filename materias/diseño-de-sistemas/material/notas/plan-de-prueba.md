# Plan de prueba

> El plan de prueba es el artefacto que indica el porcentaje de pruebas que deberían ejecutarse con un resultado específico.

En el flujo de trabajo, el plan de prueba es la salida de la actividad de planear la prueba y se usa como entrada para diseñar la prueba. También sirve de base para evaluar la prueba.
