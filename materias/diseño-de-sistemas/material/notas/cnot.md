# CNOT

> CNOT (controlled not) es un operador cuántico de dos qubits que aplica un NOT al segundo qubit solo si el primer qubit, el de control, es 1; si el control es 0, el segundo queda sin cambios.

CNOT es el operador principal de dos qubits. El primer qubit es el bit de control: si es 1, la operación realiza un NOT sobre el segundo qubit; si es 0, el segundo qubit permanece sin cambios.
