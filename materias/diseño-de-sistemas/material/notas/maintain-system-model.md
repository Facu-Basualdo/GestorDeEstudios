# Maintain System Model

> Maintain System Model es una táctica de soporte a la iniciativa del sistema que mantiene un modelo explícito del propio sistema para determinar el comportamiento esperado y dar feedback al usuario.

Este modelo se usa para determinar el comportamiento esperado del sistema y así poder dar la retroalimentación adecuada al usuario. Una manifestación común es la barra de progreso, que predice el tiempo necesario para completar la actividad actual.
