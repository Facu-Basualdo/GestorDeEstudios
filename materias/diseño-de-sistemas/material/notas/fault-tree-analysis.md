# Fault Tree Analysis (FTA)

> Fault Tree Analysis (FTA) es un enfoque deductivo de arriba hacia abajo para identificar fallas que podrían llevar al sistema a un estado inseguro.

FTA se utiliza al arquitecturar para safety, junto con FMEA, para identificar fallas que podrían mover al sistema a un unsafe state. Una vez identificadas las fallas, se deben diseñar mecanismos para detectar y mitigar la falla (y finalmente el peligro).
