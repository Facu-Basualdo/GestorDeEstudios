# Open System

> Sistema que define un conjunto de estándares para los elementos de software —cómo se comportan, cómo interactúan y cómo comparten datos— con el objetivo de habilitar y alentar a muchos proveedores a producir elementos.

La meta de un open system es evitar el vendor lock-in, una situación en la que un solo proveedor es el único que puede proporcionar un elemento y cobra un precio premium por ello.

Los open systems están habilitados por una arquitectura que define los elementos y sus interacciones.
