# Estructuras de módulos

> Las estructuras de módulos son una forma estática de modelar el sistema mediante sus particiones implementadas.

Son típicas construcciones que se pueden mapear y, de los conceptos de UML, son las que más se parecen. Cada equipo de trabajo se especializa en hacer uno u otro módulo. Las estructuras de módulo permiten preguntarse:
- ¿Cuál es la funcionalidad principal asignada a cada módulo?
- ¿Qué otros elementos de software son módulos permitidos para usar?
- ¿Qué otro software usa este módulo y depende de él?
- ¿Qué módulos están relacionados y qué tipo de relación hay entre ellos?
