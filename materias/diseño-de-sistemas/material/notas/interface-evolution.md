# Interface Evolution

> La evolución de una interfaz es el proceso de cambiar una interfaz que actúa como contrato entre un elemento y sus actores, usando deprecación, versionado o extensión.

Todo software evoluciona, incluidas las interfaces. El software encapsulado por una interfaz puede evolucionar sin afectar a los elementos que la usan mientras la interfaz no cambie. Una interfaz, sin embargo, es un contrato y debe cambiarse con cuidado. Las tres técnicas para cambiarla son deprecación, versionado y extensión.
