# object diagram

> Un object diagram muestra exclusivamente instancias de objetos en un momento dado, proporcionando una instantánea de la estructura de objetos en tiempo de ejecución.

Los objetos se nombran como 'aSomething', donde Something es la clase del objeto. El símbolo para un objeto es una caja redondeada con una línea que separa el nombre del objeto de las referencias a objetos. Las flechas indican el objeto referenciado. Ver Figure B.2.
