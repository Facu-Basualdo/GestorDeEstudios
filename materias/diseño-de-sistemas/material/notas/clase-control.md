# Clase control

> Estereotipo de clase de análisis que se usa para los casos de uso, sabe a quién llamar para hacer las cosas y cómo llevar a cabo un caso de uso o un cálculo complejo.

Aplica el patrón GRASP (Controlador).
La clase control termina cuando termina el CU y se destruye.
La clase de Sistema ya debería estar despejada y debería haber un controlador por cada CU.
