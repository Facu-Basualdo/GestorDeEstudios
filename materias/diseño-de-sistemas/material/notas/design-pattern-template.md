# Design Pattern Template

> El template de descripción de patrones es un formato consistente que divide cada patrón en secciones como Nombre y Clasificación, Intención, También Conocido Como, Motivación, Aplicabilidad, Estructura, Participantes, Colaboraciones, Consecuencias, Implementación, Código de Ejemplo, Usos Conocidos y Patrones Relacionados.

El template proporciona una estructura uniforme para describir patrones de diseño, facilitando su aprendizaje, comparación y uso. Las secciones son:
- Pattern Name and Classification
- Intent
- Also Known As
- Motivation
- Applicability
- Structure
- Participants
- Collaborations
- Consequences
- Implementation
- Sample Code
- Known Uses
- Related Patterns
