# Formal Technical Review

> Un FTR es una reunión de revisión formal donde se examina un producto de trabajo para identificar defectos, con salidas como una lista de problemas y un informe de resumen.

Durante el FTR, un revisor (el registrador) registra activamente todos los problemas planteados. Al final de la reunión se resumen y se produce una lista de problemas de revisión (review issues list). Además, se completa un informe de resumen de revisión técnica formal (review summary report) que responde: ¿Qué se revisó? ¿Quién lo revisó? ¿Cuáles fueron los hallazgos y conclusiones? El informe es una página única (con posibles anexos) y pasa a formar parte del registro histórico del proyecto. Se deben establecer procedimientos de seguimiento para asegurar que los problemas se corrijan.
