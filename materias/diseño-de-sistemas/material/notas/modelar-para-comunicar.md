# Modelar para Comunicar

> Crear modelos prolijos para comunicarse con personas externas al equipo o para crear modelos de contrato.

Una objetivo secundario del modelado es para comunicarse con personas externas al equipo o para crear modelos de contrato. Debido a que los clientes para estos modelos están fuera del equipo, debe invertirse tiempo en hacer modelos 'prolijos' utilizando normalmente herramientas electrónicas como diagramadores o procesadores de palabras.
