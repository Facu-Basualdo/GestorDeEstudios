# Usability

> La usability se ocupa de cuán fácil le resulta al usuario llevar a cabo una tarea deseada y del tipo de soporte que el sistema proporciona.

Usability comprende las siguientes áreas:
- **Aprender las funciones del sistema**: qué puede hacer el sistema para facilitar el aprendizaje, por ejemplo proveyendo ayuda.
- **Usar el sistema eficientemente**: qué puede hacer el sistema para que el usuario sea más eficiente, por ejemplo permitirle redirigir el sistema después de emitir un comando.
- **Minimizar el impacto de los errores del usuario**: qué puede hacer el sistema para que un error del usuario tenga un impacto mínimo, por ejemplo cancelar un comando emitido incorrectamente o deshacer sus efectos.
- **Adaptar el sistema a las necesidades del usuario**: cómo el usuario o el sistema pueden adaptarse para facilitar la tarea, por ejemplo completar URLs automáticamente según entradas pasadas.
- **Aumentar la confianza y la satisfacción**: qué hace el sistema para dar confianza de que se está tomando la acción correcta, por ejemplo feedback con porcentaje de completado en tareas largas.

Existe una fuerte conexión entre usability y modifiability: el proceso de diseño de la interfaz de usuario se itera, y la arquitectura debe hacer esa iteración menos dolorosa.
