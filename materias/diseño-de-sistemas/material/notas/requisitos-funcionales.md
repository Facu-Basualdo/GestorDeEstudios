# Requisitos funcionales

> Son los requisitos que se capturan a través de los casos de uso de sistema.

- Los casos de uso de sistema están pensados para capturar requisitos funcionales.
- No es una herramienta tan útil para capturar requisitos no funcionales.
- Los casos de uso también pueden servir como puntos de concentración o agrupamientos.
