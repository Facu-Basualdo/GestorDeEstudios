# Review Summary Report

> El review summary report es un formulario de una página que resume los resultados de una revisión técnica formal, respondiendo qué se revisó, quién lo revisó y cuáles fueron los hallazgos.

El informe de resumen de revisión es un formulario de una página (con posibles anexos). Forma parte del registro histórico del proyecto y puede distribuirse al líder del proyecto y otras partes interesadas.
