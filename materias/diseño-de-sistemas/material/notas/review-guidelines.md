# Review Guidelines

> Las review guidelines son un conjunto de pautas para conducir revisiones técnicas formales de manera efectiva, incluyendo recomendaciones sobre el tono, la agenda, el debate, la toma de notas, el número de participantes, etc.

Las pautas mínimas para revisiones técnicas formales incluyen:
1. Revisar el producto, no el productor.
2. Establecer una agenda y mantenerla.
3. Limitar el debate y la réplica.
4. Enunciar problemas pero no resolverlos en la reunión.
5. Tomar notas escritas.
6. Limitar el número de participantes y exigir preparación previa.
7. Desarrollar una lista de verificación para cada producto.
8. Asignar recursos y programar tiempo para FTRs.
9. Realizar capacitación significativa para todos los revisores.
10. Revisar las primeras revisiones.
