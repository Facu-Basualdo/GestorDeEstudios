# Unsafe State Avoidance

> Unsafe State Avoidance es una categoría de safety tactics orientada a evitar que el sistema entre en estados inseguros.

Unsafe State Avoidance es una de las tres categorías amplias de safety tactics. Dentro de esta categoría se encuentra la táctica de Substitution.
