# Actualizar Solo Cuando Sea Perjudicial

> Actualizar un modelo solo cuando el perjuicio de tenerlo desactualizado supere el costo de actualizarlo.

Debe actualizar un modelo solo cuando, el tener el modelo desactualizado produzca mayor perjuicio que el costo de actualizarlo. Con este enfoque descubrirá que solo actualiza un número pequeño de modelos, ya que los modelos no necesitan ser perfectos para aportar valor. Un mapa por ejemplo, puede estar desactualizado pero puede aún seguir siendo útil.
