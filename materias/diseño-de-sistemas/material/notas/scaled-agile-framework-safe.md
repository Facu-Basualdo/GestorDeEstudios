# Scaled Agile Framework (SAFe)

> Marco de referencia que surgió alrededor de 2007 para aplicar Agile a escala empresarial, coordinando las actividades de muchos equipos que trabajan en forma ágil.

SAFe surgió alrededor de 2007 y se ha refinado continuamente. Provee un modelo de referencia de flujos de trabajo, roles y procesos para que grandes organizaciones coordinen las actividades de muchos equipos, cada uno operando de manera ágil clásica, y produzcan sistemáticamente un sistema a gran escala. Reconoce el rol de la arquitectura mediante la intentional architecture y la contrapesa con el emergent design.
