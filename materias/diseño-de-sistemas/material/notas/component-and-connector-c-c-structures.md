# Component and Connector (C&C) Structures

> Component and Connector (C&C) Structures es una categoría de estructuras arquitectónicas compuesta por elementos que existen en tiempo de ejecución, como procesos y threads.

Es una de las tres categorías de estructuras de la arquitectura de un sistema. Agrupa elementos dinámicos que existen en tiempo de ejecución, como procesos y threads, y sus conectores.
