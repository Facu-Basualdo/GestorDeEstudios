# Estrategia de release

> La estrategia de release es el proceso, especificado en el plan de desarrollo, para mantener actualizada la documentación importante del proyecto, incluida la documentación de arquitectura.

El plan de desarrollo debe especificar el proceso para mantener actualizada la documentación importante del proyecto, incluida la documentación de arquitectura.

Los artefactos de documentación deben estar sujetos a control de versiones, como cualquier otro artefacto importante del proyecto. El arquitecto debe planear emitir releases de la documentación para acompañar los hitos principales del proyecto, con la antelación suficiente para que los desarrolladores puedan poner la arquitectura en práctica.

Por ejemplo, se puede entregar documentación revisada al equipo de desarrollo al final de cada iteración o sprint, o con cada release incremental.
