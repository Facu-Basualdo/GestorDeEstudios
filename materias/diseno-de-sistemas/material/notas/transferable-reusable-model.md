# Transferable, Reusable Model

> La arquitectura puede transferirse y reutilizarse entre sistemas con requisitos similares, trasladando a esos sistemas todas las consecuencias de las decisiones tempranas.

Cuanto antes en el ciclo de vida se aplica la reutilización, mayor es el beneficio. Mientras que la reutilización de código ofrece un beneficio, la reutilización de arquitecturas brinda oportunidades de gran leverage para sistemas con requisitos similares.

El modelo se convierte en un activo compartido de la organización, similar a otras inversiones de capital. Una product line o familia de sistemas es un conjunto de sistemas construidos con los mismos activos compartidos; el principal de estos activos es la arquitectura, que define qué está fijo y qué es variable para todos los miembros.
