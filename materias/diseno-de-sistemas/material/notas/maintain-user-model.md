# Maintain User Model

> Maintain User Model es una táctica de soporte a la iniciativa del sistema que mantiene un modelo explícito del conocimiento, comportamiento y otras características del usuario o de una clase de usuarios.

El modelo representa el conocimiento del usuario sobre el sistema, su comportamiento en términos de tiempo de respuesta esperado, y otros aspectos específicos de un usuario o clase de usuarios. Por ejemplo, las aplicaciones de aprendizaje de idiomas monitorean constantemente las áreas donde el usuario comete errores y luego ofrecen ejercicios adicionales para corregir esos comportamientos.

Un caso especial es la personalización de la interfaz de usuario, donde el usuario puede modificar explícitamente el modelo de usuario del sistema.
