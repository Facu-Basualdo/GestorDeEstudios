# Public Cloud

> Una nube pública es una infraestructura de nube propiedad de un cloud service provider y ofrecida a cualquiera que acepte los términos de servicio y pague por su uso.

Los servicios construidos sobre esta infraestructura son accesibles en la Internet pública, aunque se pueden configurar mecanismos como firewalls para restringir la visibilidad y el acceso. Desde una perspectiva técnica, para un arquitecto no hay mucha diferencia entre las nubes privadas y las públicas.
