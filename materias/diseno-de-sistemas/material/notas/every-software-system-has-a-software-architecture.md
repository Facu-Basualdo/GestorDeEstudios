# Every Software System Has a Software Architecture

> Todo sistema de software tiene una arquitectura, porque todo sistema tiene elementos y relaciones, aunque esa arquitectura no sea conocida por nadie.

Que todo sistema tenga una arquitectura no implica que esa arquitectura sea conocida. Quizá todos los diseñadores del sistema ya no estén, la documentación haya desaparecido o nunca se haya producido, el código fuente se haya perdido o nunca se haya entregado, y solo tengamos el binario ejecutable.

Esto revela la diferencia entre la arquitectura de un sistema y la representación de esa arquitectura. Dado que una arquitectura puede existir independientemente de su descripción, esto resalta la importancia de la documentación de la arquitectura, que se describe en el capítulo 22.
