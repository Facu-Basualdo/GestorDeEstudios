# Rationale

> Razones que motivan una design decision y que se registran para facilitar el análisis y la comprensión posterior.

Junto con las design decisions se debe registrar el rationale, es decir, las razones que motivaron esas decisiones. Esto permite analizar y entender las decisiones más adelante. Por ejemplo, las decisiones sobre tradeoffs importantes deben quedar registradas con su rationale.
