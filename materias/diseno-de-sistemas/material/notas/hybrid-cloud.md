# Hybrid Cloud

> Una nube híbrida es un modelo mixto en el que algunas cargas de trabajo se ejecutan en una nube privada y otras en una nube pública.

Se puede usar durante una migración de una nube privada a una pública (o viceversa), o porque algunos datos están legalmente obligados a estar sujetos a un mayor control y escrutinio del que una nube pública puede ofrecer.
