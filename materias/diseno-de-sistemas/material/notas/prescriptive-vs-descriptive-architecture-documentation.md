# Prescriptive vs. Descriptive Architecture Documentation

> La documentación de arquitectura puede ser prescriptiva para algunas audiencias (impone restricciones sobre decisiones futuras) y descriptiva para otras (cuenta decisiones ya tomadas).

Para algunas audiencias, la documentación prescribe lo que debería ser verdadero y coloca restricciones sobre las decisiones que aún no se tomaron. Para otras audiencias, describe lo que es verdadero y relata decisiones ya tomadas sobre el diseño del sistema. El mismo documento puede cumplir ambos roles según la audiencia.
