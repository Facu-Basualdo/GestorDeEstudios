# Designers of Other Systems

> Stakeholders que diseñan sistemas con los cuales este sistema debe interoperar, y necesitan conocer las operaciones y protocolos.

Para estos stakeholders, la arquitectura define el conjunto de operaciones provistas y requeridas, así como los protocolos para su operación. Probablemente quieran ver:
- Documentación de interfaces de los elementos con los que su sistema interactuará, en vistas de módulos y/o C&C.
- El modelo de datos del sistema.
- Diagramas de contexto de nivel superior de varias vistas que muestren las interacciones.
