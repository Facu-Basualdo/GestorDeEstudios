# Mixed Initiative

> La mixed initiative combina la user initiative y la system initiative en una misma operación.

Por ejemplo, en una cancelación, el usuario emite el cancel (user initiative) y el sistema muestra un indicador de progreso (system initiative). Así, la operación de cancelación comprende una mixed initiative.
