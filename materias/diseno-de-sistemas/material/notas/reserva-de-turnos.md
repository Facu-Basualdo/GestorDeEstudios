# Reserva de turnos

> Proceso mediante el cual un cliente registrado selecciona un servicio, completa observaciones, elige día y horario, y abona al menos el 50% para confirmar el turno.

Para realizar la reserva, el cliente debe:
- Seleccionar el servicio (depilación, limpieza de cutis, etc.).
- Completar observaciones (alergias, etc.) y características según el servicio (zona de depilación, tipo de esmaltado, etc.).
- Elegir día y horario entre los turnos disponibles.
- Realizar el pago del 50% del servicio para que el turno quede definitivamente reservado.
