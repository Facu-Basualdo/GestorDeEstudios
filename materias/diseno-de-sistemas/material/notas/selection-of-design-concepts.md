# Selection of Design Concepts

> Actividad del paso 4 de ADD que consiste en elegir el design concept más apropiado entre las alternativas identificadas, considerando criteria, drivers y restricciones.

Una vez identificada una lista de alternativas, se selecciona la más apropiada para resolver el problema de diseño. Una forma simple es crear una tabla con pros y contras de cada alternativa y elegir según esos criterios y los drivers. La tabla puede incluir otros criterios como el costo asociado. Métodos como el análisis SWOT (strengths, weaknesses, opportunities, threats) pueden ayudar. Hay que tener en cuenta las constraints que forman parte de los architectural drivers: algunas restricciones pueden impedir seleccionar ciertas alternativas (por ejemplo, que todas las librerías y frameworks tengan licencia aprobada). También las decisiones de selección de iteraciones anteriores pueden restringir las opciones actuales por incompatibilidades, como elegir una web architecture primero y luego un user interface framework para aplicaciones locales.
