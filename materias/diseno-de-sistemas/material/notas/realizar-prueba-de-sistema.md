# Realizar prueba de sistema

> Actividad del proceso de pruebas, realizada por el Ingeniero de pruebas de sistema, que ejecuta la prueba de sistema y reporta defectos a partir del caso de prueba, el procedimiento de prueba, el componente de prueba y el modelo de implementación de la construcción a probar.

El Ingeniero de pruebas de sistema es el actor responsable.

- Entradas: Caso de prueba, Procedimiento de prueba, Componente de prueba, Modelo de implementación (construcción a probar).
- Resultado: Defecto.
