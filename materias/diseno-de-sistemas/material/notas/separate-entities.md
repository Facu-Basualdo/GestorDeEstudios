# Separate Entities

> Táctica que separa distintas entidades para limitar el alcance de un ataque.

La separación puede ser física, en diferentes servidores conectados a diferentes redes; mediante máquinas virtuales; o con un 'air gap', es decir, sin conexión electrónica entre diferentes porciones del sistema. Los datos sensibles se separan frecuentemente de los no sensibles para reducir la posibilidad de ataque por parte de usuarios que tienen acceso a datos no sensibles.
