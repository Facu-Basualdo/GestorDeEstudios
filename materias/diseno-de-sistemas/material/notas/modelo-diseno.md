# Modelo de Diseño

> Modelo de mayor detalle y más costoso que el modelo de análisis, que se mantiene a lo largo del proyecto y del cual se deriva el modelo de implementación.

El modelo de análisis es genérico desde el punto de vista del dominio. Este modelo es más costoso porque tiene mayor detalle. Debe mantenerse a lo largo de todo el proyecto: los cambios se analizan de acuerdo con los costos que conlleva cada uno. En la etapa de diseño se llega al nivel de detalle máximo y, a partir de este modelo, se puede obtener el modelo de implementación.
