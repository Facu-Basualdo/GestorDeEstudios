# Implementar un subsistema

> Actividad de la implementación, realizada por el Ingeniero de componentes, que implementa un subsistema de diseño y su interfaz en un subsistema de implementación para una construcción.

El Ingeniero de componentes es el actor responsable.

- Entradas: Plan de integración de construcciones, Descripción de arquitectura (vista del modelo de implementación), Subsistema de diseño (diseñado), Interfaz (diseñado).
- Resultados: Subsistema de implementación (implementado para una construcción), Interfaz (implementado para una construcción).
