# Software Quality Assurance

> Aseguramiento de la calidad del software (SQA) es un patrón de acciones planificado y sistemático requerido para garantizar alta calidad en el software.

El grupo SQA actúa como representante del cliente dentro de la organización. Sus responsabilidades incluyen:

- **Estándares**: Asegurar que se sigan los estándares adoptados (IEEE, ISO, etc.) y que todos los productos de trabajo cumplan con ellos.
- **Revisiones y auditorías**: Las revisiones técnicas son actividades de control de calidad realizadas por ingenieros de software; las auditorías son realizadas por personal de SQA para verificar que se sigan las guías de calidad.
- **Pruebas**: Asegurar que las pruebas estén planificadas y ejecutadas adecuadamente para encontrar errores.
- **Recolección y análisis de errores/defectos**: Recopilar y analizar datos de errores para entender cómo se introducen y qué actividades ayudan a eliminarlos.
- **Gestión de cambios**: Asegurar prácticas adecuadas de gestión de cambios.
- **Educación**: Liderar la mejora de procesos y patrocinar programas educativos.
- **Gestión de proveedores**: Asegurar calidad en software adquirido externamente.
- **Gestión de seguridad**: Implementar políticas de protección de datos y seguridad.
- **Seguridad (safety)**: Evaluar el impacto de fallos y reducir riesgos en sistemas críticos.
- **Gestión de riesgos**: Asegurar que las actividades de gestión de riesgos se realicen adecuadamente.

Además, el grupo SQA realiza tareas específicas (según SEI):
- Preparar un plan SQA para el proyecto.
- Participar en el desarrollo de la descripción del proceso de software.
- Revisar actividades de ingeniería para verificar cumplimiento del proceso.
- Auditar productos de trabajo designados.
- Asegurar que las desviaciones se documenten y manejen según procedimientos.
- Registrar incumplimientos y reportar a la alta gerencia.

También coordina el control y gestión de cambios y ayuda a recolectar y analizar métricas de software.
