# Codificación Estándar

> Práctica de XP que consiste en seguir una codificación estándar común para que todo el código parezca escrito por la misma persona y favorezca la propiedad colectiva.

Los equipos XP siguen una codificación estándar común, de tal modo que todo el código en el sistema parece ser escrito por la misma persona. Además la codificación estándar favorece la propiedad colectiva del código.
