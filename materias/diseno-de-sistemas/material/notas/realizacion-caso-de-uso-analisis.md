# Realización de caso de uso en el análisis

> Conjunto de clases e interacciones necesarias para llevar a cabo un caso de uso a nivel de análisis.

En cada realización se define un conjunto de clases y las interacciones necesarias para el CU.
El PU divide la realización en dos partes: a nivel de análisis y a nivel de diseño.
Estas realizaciones se modelan a través de Diagramas de Comunicación.
Si un CU sufre una modificación, todas las clases se ven afectadas.
El flujo de eventos de análisis es la descripción textual para los diagramas de comunicación o secuencia; incluye objetos, algo que no está permitido en la Descripción textual de un CU.
