# Class (or Generalization) Structure

> La class structure (estructura de clases o generalización) relaciona clases mediante las relaciones "inherits-from" o "is-an-instance-of".

Permite razonar sobre colecciones de comportamiento o capacidad similares y diferencias parametrizadas. También permite razonar sobre reutilización y agregación incremental de funcionalidad. Si existe documentación de un proyecto que siguió un proceso de análisis y diseño orientado a objetos, típicamente es esta estructura.
