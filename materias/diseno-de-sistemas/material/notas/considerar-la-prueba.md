# Considerar la Prueba

> Considerar la prueba de cada artefacto que se construye, de modo que todo lo que se construya sea probado.

Una filosofía útil es que todo lo que vaya a construirse debe poder ser probado, sino no hay que construirlo. Debe considerarse la prueba de cada artefacto que se construye. Probando un artefacto con código, se comprueba que el sistema es verificable.
