# Instance

> Un objeto creado al instanciar una clase es una instancia de esa clase.

El proceso de instanciar una clase asigna almacenamiento para los datos internos del objeto (variables de instancia) y asocia las operaciones con esos datos. Se pueden crear muchas instancias similares instanciando una clase.
