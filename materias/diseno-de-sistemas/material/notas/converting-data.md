# Converting Data

> Convertir datos es la función del sensor stack que transforma las lecturas del formato informado por el sensor a una forma común significativa para la aplicación.

Los sensores pueden reportar en muchos formatos, por ejemplo desde milivoltios hasta altitud sobre el nivel del mar en pies o temperatura en grados Celsius. Dos sensores que miden el mismo fenómeno pueden reportar en formatos distintos; el conversor debe lidiar con una amplia variedad de sensores.
