# Encontrar actores y casos de uso

> Actividad de la captura de requisitos que identifica los actores y casos de uso, produciendo un modelo de casos de uso esbozado y requisitos adicionales.

Según la Figura 7.11, las entradas de esta actividad son: el modelo del negocio (o modelo de dominio), el analista de sistemas, el glosario y la lista de características. Los resultados son: el modelo de casos de uso (esbozado) y los requisitos adicionales.
