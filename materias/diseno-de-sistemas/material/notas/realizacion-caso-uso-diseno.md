# Realización de Caso de Uso de Diseño

> Realización de un caso de uso en la etapa de diseño, con otro nivel de detalle, apoyada en diagramas de interacción basados en diagramas de secuencia.

El ingeniero de casos de uso ahora tiene la realización de casos de uso, pero de diseño. Los diagramas de interacción se van a basar más en los diagramas de secuencia. El Proceso Unificado recomienda usar diagramas de secuencia para mostrar la interacción.
