# Smart Battery

> Una smart battery (batería inteligente) es una batería recargable con un sistema de gestión de batería (BMS) integrado que puede consultarse para conocer su estado.

La mayoría de las laptops y smartphones usan una smart battery como fuente de energía. El BMS puede ser consultado para obtener el estado actual de la batería. Otros sistemas móviles pueden usar una tecnología de batería diferente, pero todos tienen alguna capacidad equivalente. En esta sección se asume que la lectura identifica el porcentaje de capacidad restante.
