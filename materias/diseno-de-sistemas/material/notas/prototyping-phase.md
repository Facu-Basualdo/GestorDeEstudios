# Prototyping Phase

> Fase inicial del ciclo de vida del software orientado a objetos, caracterizada por prototipado rápido y cambios incrementales hasta alcanzar los requisitos iniciales.

Durante la fase de prototipado, el software se crea mediante prototipado rápido y cambios incrementales, hasta que cumple un conjunto inicial de requisitos y alcanza la 'adolescencia'. En esta fase, el software suele consistir en jerarquías de clases que reflejan entidades del dominio del problema inicial. El principal tipo de reutilización es la reutilización de caja blanca (white-box reuse) mediante herencia.
