# Checksum

> Mecanismo de validación en el que el sistema mantiene por separado información redundante para archivos y mensajes y la usa para verificar el archivo o mensaje.

Es una de las técnicas empleadas por la táctica verify message integrity para verificar la integridad de mensajes, archivos de recursos, archivos de despliegue y archivos de configuración.
