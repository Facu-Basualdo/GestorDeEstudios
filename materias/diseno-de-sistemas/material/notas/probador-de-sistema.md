# Probador de sistema

> El probador de sistema (o ingeniero de pruebas de sistema) verifica que el sistema interactúe correctamente con el usuario del sistema.

Normalmente esto viene asociado con los CU. Al ejecutar la prueba, si existiesen, aparece un conjunto de defectos.
