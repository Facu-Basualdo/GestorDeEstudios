# Caso de prueba de regresión

> Un caso de prueba de regresión prueba el sistema hacia atrás, para comprobar que el sistema completo sigue funcionando después de un cambio.

Puede haber casos donde necesite probar todo el sistema completo para ver si sigue funcionando. Básicamente debe ser un caso de prueba que pueda cambiar y convenga seguir probándolo: si al primer cambio ya queda obsoleto, es muy costoso y no conviene.
