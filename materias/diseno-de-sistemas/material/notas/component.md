# Component

> Un component (componente) es un elemento de una C&C view que tiene presencia en runtime, como procesos, servicios, objetos, clientes, servidores y data stores.

Un component puede representar un subsistema complejo, que a su vez puede describirse como una subarquitectura C&C; esa subarquitectura puede emplear un patrón distinto del que aparece en el component.

Cada element de una C&C view debe tener un nombre y un tipo, con propiedades adicionales que dependen del tipo de component o connector.
