# Actividades básicas de XP

> Las actividades básicas de XP son programar, probar, escuchar y diseñar.

Programar: es la actividad principal. Probar: es central, porque permite saber si el código funciona; aunque no sea rigurosa, la etapa de pruebas es sobresaliente en el framework. Escuchar: implica feedback o retroalimentación, por ejemplo del cliente. Diseño: se hace poco foco; solo para mejorar lo que ya está hecho. Mnemotecnia: PPED.
