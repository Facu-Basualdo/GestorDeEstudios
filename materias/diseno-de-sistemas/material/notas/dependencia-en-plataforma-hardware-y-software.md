# Dependencia en plataforma de hardware y software

> Depender de una plataforma particular dificulta portar el software a otras plataformas e incluso mantenerlo actualizado en su plataforma nativa.

Es importante diseñar el sistema para limitar las dependencias de plataforma. Patrones: Abstract Factory (87), Bridge (151).
