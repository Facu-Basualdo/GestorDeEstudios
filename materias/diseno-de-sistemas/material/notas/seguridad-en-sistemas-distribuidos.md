# Seguridad en sistemas distribuidos

> Punto de diseño que pregunta cómo definir e implementar políticas de seguridad útiles para un conjunto de sistemas gestionados de forma independiente.

En los sistemas distribuidos, la principal dificultad radica en establecer una política de seguridad que pueda aplicarse de forma fiable a todos los componentes del sistema.

Una política de seguridad define el nivel de seguridad que debe alcanzar un sistema. Los mecanismos de seguridad, como el cifrado y la autenticación, se utilizan para hacer cumplir esa política.

Las dificultades surgen porque distintas organizaciones pueden ser propietarias de partes del sistema y tener políticas y mecanismos de seguridad incompatibles entre sí. Por lo tanto, puede ser necesario hacer concesiones en materia de seguridad para permitir que los sistemas funcionen conjuntamente.
