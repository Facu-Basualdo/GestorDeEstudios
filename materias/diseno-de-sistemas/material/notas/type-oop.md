# Type

> El tipo de un objeto se refiere a su interfaz: el conjunto de peticiones a las que puede responder.

Un objeto puede tener muchos tipos, y objetos de diferentes clases pueden tener el mismo tipo. Existe una relación estrecha entre clase y tipo, ya que una clase también define un tipo, pero no son lo mismo.
