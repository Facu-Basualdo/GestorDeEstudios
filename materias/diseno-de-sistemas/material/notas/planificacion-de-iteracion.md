# Planificación de Iteración

> Planificación detallada al comienzo de cada iteración en XP para asignar historias de usuario y tareas de programación.

Una reunión de planificación de iteración es realizada al comienzo de cada iteración para producir un plan de tareas de programación a realizar durante la iteración. Cada iteración tiene una duración de entre 1 a 3 semanas. Las historias de usuario son seleccionadas para la iteración por el cliente del plan de entregas. También se seleccionan las pruebas de aceptación fallidas a corregir. Las historias de usuario y pruebas de aceptación fallidas son trasladadas en tareas de programación, las cuales son escritas en tarjetas. Estas tarjetas constituyen el plan detallado para la iteración. Cada tarea tiene una duración típica de 1 a 3 días. Las tareas que son más breves que un día pueden agruparse en el mismo día. Tareas de mayor duración a 3 días deben descomponerse en otras menores.
