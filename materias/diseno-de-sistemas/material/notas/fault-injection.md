# Fault Injection

> Fault injection es una técnica que coloca fallas en el sistema en ejecución de manera controlada y monitoreada.

Algunos miembros del Simian Army de Netflix usaban fault injection como parte de sus pruebas. Permite colocar fallas en el sistema en ejecución de manera controlada y monitoreada, para observar el efecto de esas fallas y verificar que el sistema no falle ni se degrade seriamente.
