# Proceso Unificado

> El Proceso Unificado es un proceso de desarrollo genérico para sistemas complejos, dirigido por casos de uso y del que deriva RUP.

- RUP a veces se lo menciona como proceso unificado porque uno deriva del otro, aunque no son lo mismo.
- En PU se usa el término "trabajador" donde RUP usa "rol".
- RUP tiene más disciplinas y mucho más detalle que PU; RUP junta algunas disciplinas del PU.
- PU es un proceso de desarrollo para sistemas complejos y un desarrollo más formal.
- No se puede considerar PU a algo que no usa casos de uso.
