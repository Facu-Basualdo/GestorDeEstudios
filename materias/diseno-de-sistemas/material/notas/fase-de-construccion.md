# Fase de construcción

> Fase en la que se desarrolla el producto de software y se obtiene una versión funcional completa del sistema.

- En esencia es desarrollar el producto de software.
- Deberían estar definidos todos los casos de uso.
- El artefacto más importante es el software ejecutable.
- Al final de esta fase el sistema está desarrollado casi en su totalidad, aunque no está libre de errores.
