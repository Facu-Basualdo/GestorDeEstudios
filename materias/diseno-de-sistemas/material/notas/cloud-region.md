# Cloud Region

> Una cloud region es una construcción lógica y física que organiza los data centers de un proveedor de nube para acercar los servicios a sus usuarios y cumplir restricciones regulatorias.

Cuando se accede a una nube pública a través de un proveedor, en realidad se accede a data centers distribuidos por el mundo. El proveedor organiza sus data centers en regiones. Las regiones ayudan a que el servicio esté físicamente cerca de sus usuarios, reduciendo la demora de red. También ayudan a cumplir regulaciones como el GDPR, que puede restringir la transmisión de ciertos tipos de datos a través de fronteras nacionales.
