# Manage Deployment Pipeline

> Manage Deployment Pipeline es una categoría de tactics for deployability que agrupa estrategias para gestionar el pipeline de despliegue.

La primera categoría de tácticas de deployability se centra en estrategias para gestionar el pipeline de despliegue. Incluye las tácticas **scale rollouts**, **roll back** y **script deployment commands**.
