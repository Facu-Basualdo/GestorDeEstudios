# Audit

> Táctica de recuperación que mantiene un registro de las acciones de usuarios y sistemas y sus efectos para rastrear e identificar a un atacante.

Se auditan los sistemas para ayudar a rastrear las acciones de un atacante e identificarlo. Los registros de auditoría pueden analizarse para intentar procesar a los atacantes o para crear mejores defensas en el futuro.
