# DMAIC

> DMAIC es un método de Six Sigma que consta de cinco pasos: definir, medir, analizar, mejorar y controlar.

DMAIC se utiliza cuando se requiere mejorar un proceso existente. Los pasos son:
- Definir los requisitos del cliente y las metas del proyecto.
- Medir el proceso actual para determinar el rendimiento de calidad.
- Analizar las métricas de defectos para determinar las causas raíz.
- Mejorar el proceso eliminando las causas raíz de los defectos.
- Controlar el proceso para asegurar que no se reintroduzcan las causas de los defectos.
