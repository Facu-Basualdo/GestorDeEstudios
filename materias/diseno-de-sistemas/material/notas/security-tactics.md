# Security Tactics

> Cuatro categorías de tácticas para lograr seguridad en un sistema: detect, resist, react y recover.

Pensar en la seguridad física sugiere tácticas: limitar el acceso (cercas, puestos de control), detectar intrusos (exigir credenciales), disuadir (guardias armados), reaccionar (cerraduras automáticas de puertas) y recuperarse (backup fuera de sitio). Estas llevan a las cuatro categorías de tácticas de seguridad: detect (detectar), resist (resistir), react (reaccionar) y recover (recuperar).
