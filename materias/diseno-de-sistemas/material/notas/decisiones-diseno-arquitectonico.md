# Decisiones del diseño arquitectónico

> Preguntas clave que el arquitecto debe responder al diseñar la arquitectura, referidas a distribución, control, documentación, requisitos no funcionales y patrones.

Algunas decisiones son:
- Cómo se distribuirá el sistema entre núcleos o procesadores del hardware.
- Qué estrategia se usará para controlar la operación del sistema.
- Cómo se documentará la arquitectura.
- Cuál es la mejor organización para los requisitos no funcionales.
- Qué patrones o estilos arquitectónicos se utilizarán.
- Cómo se descompondrán los componentes en subcomponentes.
- Cuál será el enfoque fundamental para estructurar el sistema (repositorios vs. pipe-and-filter).

No se suele usar un modelado tan detallado porque es muy complicado y caro.
