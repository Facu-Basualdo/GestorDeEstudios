# Dynamic Binding

> La asociación en tiempo de ejecución de una solicitud a un objeto y una de sus operaciones se conoce como dynamic binding.

Dynamic binding significa que emitir una solicitud no te compromete a una implementación particular hasta tiempo de ejecución. Como consecuencia, se pueden escribir programas que esperan un objeto con una interfaz particular, sabiendo que cualquier objeto que tenga la interfaz correcta aceptará la solicitud. Dynamic binding permite sustituir objetos con interfaces idénticas entre sí en tiempo de ejecución.
