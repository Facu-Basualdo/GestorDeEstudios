# Usability Tactics

> Las usability tactics (tácticas de usabilidad) son un conjunto de tácticas arquitectónicas que mejoran la usabilidad de un sistema en ejecución, ya sea apoyando la iniciativa del usuario o la iniciativa del sistema.

El objetivo de estas tácticas se muestra en la Figura 13.2. Se dividen en dos grupos:

* **Support User Initiative**: incluye las tácticas cancel, undo, pause/resume y aggregate, que ayudan al usuario a corregir errores o ser más eficiente.
* **Support System Initiative**: incluye las tácticas maintain task model, maintain user model y maintain system model, que usan modelos para predecir el comportamiento del sistema o la intención del usuario.

La Figura 13.3 resume las tácticas para lograr usabilidad.
