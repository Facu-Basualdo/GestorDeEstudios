# Clase de análisis

> Clase conceptual del análisis en la que se definen atributos y responsabilidades, sin métodos, y que puede tener estereotipos de frontera, control o entidad.

Las clases de análisis están descriptas con mayor abstracción que las de diseño.
Se definen atributos a nivel conceptual, por ejemplo "string" o "entero", y responsabilidades; no se definen métodos.
Una clase de análisis puede tener estereotipos: frontera, control y entidad.
Un ejemplo es una clase factura o un planificador de pagos que accede a las peticiones que vienen desde la clase frontera.
