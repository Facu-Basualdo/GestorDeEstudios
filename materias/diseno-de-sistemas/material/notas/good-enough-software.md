# Good Enough Software

> El software 'suficientemente bueno' entrega funciones de alta calidad que los usuarios desean, pero también funciones más oscuras o especializadas con errores conocidos.

Las empresas de software crean software con errores conocidos y lo entregan a una amplia población de usuarios, planificando mejoras en versiones posteriores. Esto funciona si el producto es 'suficientemente bueno' para la mayoría. Sin embargo, para pequeñas empresas o dominios de aplicación críticos (como software embebido en tiempo real, automotriz o de aviónica), entregar software con errores puede ser negligente y abrir litigios. El modelo de proceso debe proporcionar criterios claros para determinar qué es realmente 'suficientemente bueno' para el dominio de aplicación. Se debe proceder con cuidado; esta filosofía solo funciona para unos pocos y en un conjunto limitado de dominios.
