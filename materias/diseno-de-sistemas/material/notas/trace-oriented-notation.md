# Trace-Oriented Notation

> Tipo de notación para documentar comportamiento que describe la respuesta del sistema a estímulos específicos mediante secuencias de actividades o interacciones.

Se contrapone a las notaciones comprehensivas. En este fragmento se describen cuatro notaciones orientadas a traces: use cases, sequence diagrams, communication diagrams y activity diagrams. Existen otras notaciones como message sequence charts, timing diagrams y Business Process Execution Language, pero se eligen estas cuatro como muestra representativa.
