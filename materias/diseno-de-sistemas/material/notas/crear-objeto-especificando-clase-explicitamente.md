# Crear un objeto especificando una clase explícitamente

> Especificar un nombre de clase al crear un objeto compromete a una implementación particular en lugar de una interfaz, lo que puede complicar cambios futuros.

Para evitarlo, se deben crear objetos indirectamente. Los patrones de diseño que abordan esta causa son: Abstract Factory (87), Factory Method (107), Prototype (117).
