# Componentes de un patrón

> Los elementos que deben estar a la hora de definir un patrón son contexto, problema y solución.

- El contexto se aclara porque la solución no es universal; es el componente considerado menos importante.
- Los elementos necesarios para definir un patrón son: contexto, problema y solución.
