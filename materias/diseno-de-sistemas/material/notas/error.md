# Error

> Un error es un problema de calidad descubierto antes de que el software sea liberado a los usuarios finales u otras partes interesadas.

En este libro se hace una clara distinción entre un error (un problema de calidad encontrado antes de que el software sea liberado a otras partes interesadas o usuarios finales) y un defecto (un problema de calidad encontrado solo después de que el software ha sido liberado). Esta distinción temporal no es la corriente principal; la comunidad de ingeniería de software generalmente considera que defectos, errores, fallas y bugs son sinónimos. Sin embargo, el punto en el tiempo en que se descubre un problema sí importa.
