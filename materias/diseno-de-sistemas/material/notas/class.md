# Class

> La clase define la implementación de un objeto: sus datos internos y las operaciones que puede realizar.

En la notación OMT, una clase se representa como un rectángulo con el nombre en negrita. Las operaciones aparecen en tipo normal debajo del nombre. Cualquier dato que la clase define viene después de las operaciones. Los tipos de retorno y tipos de variables de instancia son opcionales, ya que no se asume un lenguaje de tipos estáticos.
