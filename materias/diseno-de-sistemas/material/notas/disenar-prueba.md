# Diseñar prueba

> Actividad del proceso de pruebas, realizada por el Ingeniero de pruebas, que produce el caso de prueba y el procedimiento de prueba a partir de los modelos y del plan de prueba.

El Ingeniero de pruebas es el actor responsable.

- Entradas: Requisitos adicionales, Modelo de casos de uso, Modelo de análisis, Modelo de diseño, Modelo de implementación, Descripción de arquitectura (vistas arquitectónicas de los modelos), Plan de prueba (estrategia de prueba y planificación).
- Resultados: Caso de prueba, Procedimiento de prueba.
