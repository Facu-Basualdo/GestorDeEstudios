# Structures as Engineering Leverage Points

> Las structures de una arquitectura son los puntos de apalancamiento de ingeniería principales, ya que cada una permite manipular uno o más quality attributes.

Las structures representan un enfoque poderoso para crear la arquitectura y, más tarde, para analizarla y explicarla a los stakeholders. Las structures que el arquitecto elige como puntos de apalancamiento también son las candidatas principales para servir de base a la documentación de la arquitectura.
