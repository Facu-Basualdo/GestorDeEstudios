# Communications View

> Una communications view muestra todos los canales entre componentes, canales de red, valores de parámetros de calidad de servicio y áreas de concurrencia.

Puede ser especialmente útil para sistemas globalmente dispersos y heterogéneos. Se usa para analizar ciertos tipos de rendimiento y fiabilidad, como detección de deadlock o condición de carrera. También puede mostrar, por ejemplo, cómo se asigna dinámicamente el ancho de banda de red.
