# User Initiative

> La user initiative describe el caso en que el usuario toma la iniciativa en la interacción con el sistema.

Por ejemplo, al cancelar un comando, el usuario emite una cancelación (user initiative) y el sistema responde. El término se usa para describir cuál de los dos, humano o computadora, toma la iniciativa en realizar ciertas acciones y cómo procede la interacción.
