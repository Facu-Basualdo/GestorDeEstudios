# Modelo de negocio

> El modelo de negocio describe en alto nivel el dominio del problema o modela el negocio y sus entidades.

- Sirve para mencionar en alto nivel el dominio del problema.
- A veces no es necesario hacer este modelado porque lleva mucho tiempo.
- Consiste en modelar el modelo de negocio y las entidades que se van a manejar; es un conjunto de entidades vinculadas.
- Un caso especial del modelo de negocio es el modelo de dominio, modelado a través de clases conceptuales.
- Se distinguen los CU de negocio y los CU de sistema; el CU de negocio modela procesos del negocio.
- El actor de negocio es externo al negocio y se suele confundir con el trabajador.
