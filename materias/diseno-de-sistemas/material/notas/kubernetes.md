# Kubernetes

> Kubernetes es un software de orquestación de código abierto para desplegar, administrar y escalar containers.

En la jerarquía de Kubernetes, los nodos (hardware o VMs) contienen Pods, y los Pods contienen containers. Añade un elemento más a la jerarquía: los Pods.
