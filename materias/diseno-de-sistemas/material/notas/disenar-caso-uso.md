# Diseñar un Caso de Uso

> Actividad del flujo de diseño que realiza la realización de un caso de uso con otro nivel de detalle y captura requisitos de implementación.

Se hace la realización de manera análoga al análisis pero con otro nivel de detalle. Se agregan como entrada el modelo de diseño y el de despliegue, y se saca la descripción de la arquitectura. Subactividades: identificación de clases de diseño participantes, descripción de las interacciones entre objetos de diseño, identificación de subsistemas e interfaces participantes, descripción de interacciones entre subsistemas y captura de requisitos de implementación.
