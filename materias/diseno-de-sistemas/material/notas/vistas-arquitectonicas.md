# Vistas Arquitectónicas

> Son las diferentes perspectivas desde las que se modela un sistema, porque es imposible representar toda la información relevante en un solo diagrama.

Existen cuatro perspectivas arquitectónicas fundamentales, que pueden vincularse mediante casos de uso o escenarios comunes:

- **Vista lógica**: muestra las abstracciones claves como objetos y clases. Se debería poder relacionar los requisitos del sistema con entidades de esta vista.
- **Vista de procesos**: muestra, en tiempo de ejecución, cómo el sistema se compone de procesos. Sirve para comprobar requisitos no funcionales como rendimiento y disponibilidad.
- **Vista de desarrollo**: muestra cómo el software se descompone para el desarrollo, es decir, en componentes implementados por un desarrollador o un grupo de ellos. Es útil para programadores y managers.
- **Vista física**: muestra el hardware y software y cómo están distribuidos para formar el sistema. Es útil para los ingenieros en sistemas que planean un despliegue del sistema.

Las vistas se diseñan casi siempre en la etapa de diseño y se utilizan para mostrar a los stakeholders o informar decisiones arquitecturales.
