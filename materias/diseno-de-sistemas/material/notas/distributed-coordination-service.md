# Distributed Coordination Service

> Un distributed coordination service es un servicio que permite compartir pequeñas cantidades de datos entre las instancias de un servicio.

Los distributed coordination services permiten compartir pequeñas cantidades de datos entre las instancias de un servicio. Son complicados de implementar, pero existen varias implementaciones open source probadas que se pueden usar.
