# Patterns for Testability

> Los patrones para testability hacen más fácil desacoplar el código específico de prueba de la funcionalidad real de un sistema.

Se presentan tres patrones para testability: dependency injection, strategy e intercepting filter. Todos comparten el objetivo de facilitar el desacoplamiento entre el código de prueba y la funcionalidad del sistema.
