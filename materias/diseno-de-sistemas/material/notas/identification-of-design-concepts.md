# Identification of Design Concepts

> Actividad del paso 4 de ADD que consiste en identificar los design concepts alternativos que podrían ayudar a lograr las metas de la iteración.

La identificación puede parecer abrumadora por la gran cantidad de opciones: hay docenas de design patterns y externally developed components posibles, dispersos en blogs, sitios web, literatura de investigación y libros. Muchas veces no hay una definición canónica; por ejemplo, el broker pattern se define de maneras diferentes e informales. Para abordar un problema específico se pueden combinar distintos tipos de design concepts, como un security pattern, una security tactic y un security framework. Las técnicas para identificar alternativas incluyen:

- Aprovechar best practices existentes: usar catálogos; permite identificar muchas alternativas y aprovechar conocimiento ajeno, pero requiere tiempo, y la calidad y supuestos de los autores son desconocidos.
- Aprovechar el conocimiento y la experiencia propios: rápido y confiable si el sistema es similar a otros diseñados antes, pero puede llevar a repetir las mismas ideas aunque no sean las más apropiadas ('si solo tienes un martillo, todo parece un clavo').
- Aprovechar el conocimiento y la experiencia de otros: hacer la identificación y selección con colegas mediante brainstorming.
