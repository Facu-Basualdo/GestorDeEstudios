# Module Size

> Module size es una caracteristica que afecta el costo y la complejidad de un cambio: en igualdad de condiciones, los modulos mas grandes son mas dificiles y costosos de cambiar.

Los modulos mas grandes son mas propensos a tener errores. La reduccion del tamano es uno de los parametros que las tacticas de modificabilidad pueden afectar.
