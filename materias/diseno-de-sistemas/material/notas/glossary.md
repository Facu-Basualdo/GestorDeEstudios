# Glossary

> Artefacto que clarifica detalles de parámetros o datos de la capa de UI, datos que se pasan a la base de datos y lógica o validaciones específicas de ítems.

El glosario clarifica detalles de parámetros o datos que vienen de la capa de UI, datos que se pasan a la base de datos y lógica o requerimientos de validación específicos de un ítem, como los formatos legales y la validación para UPC. Es una entrada al diseño de objetos.
