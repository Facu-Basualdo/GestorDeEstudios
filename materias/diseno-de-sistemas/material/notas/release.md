# Release

> Es una versión utilizable del producto de software que se obtiene al final de un ciclo o iteración; puede ser externa, para el cliente, o interna, para el equipo.

Al final del primer ciclo se obtiene una release, es decir, una versión utilizable del producto que se puede usar en producción. En la primera fase la release puede no ser tan ejecutable, pero igual se la considera release. Existen release externas, para presentar al cliente, y release internas, que quedan dentro del equipo de trabajo. El resultado de cada iteración son versiones internas o incrementos: no se entregan al cliente, pero permiten ver el progreso, probar y obtener feedback.
