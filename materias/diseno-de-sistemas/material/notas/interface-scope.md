# Interface Scope

> El alcance de una interfaz define la colección de recursos directamente disponibles para los actores.

El diseñador puede revelar todos los recursos o restringir el acceso a ciertos recursos o a ciertos actores. Las restricciones pueden deberse a razones de seguridad, gestión de rendimiento y extensibilidad.
