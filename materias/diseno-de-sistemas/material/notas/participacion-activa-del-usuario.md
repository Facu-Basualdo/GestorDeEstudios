# Participación Activa del Usuario

> Práctica central de Agile Modeling que requiere la participación activa del usuario final para comprender y satisfacer sus requerimientos.

La Participación Activa del Usuario es crítica ya que es para él para quién se desarrolla el sistema y cuyos requerimientos deben ser comprendidos y satisfechos. Esta práctica es a su vez soportada por la práctica de Modelar con Otros, siendo el usuario en este caso el 'otro'.
