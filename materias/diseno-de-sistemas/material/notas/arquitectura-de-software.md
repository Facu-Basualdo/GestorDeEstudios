# Arquitectura de software

> La arquitectura de software es el modelo de un sistema con el nivel de abstracción necesario para comprenderlo en su totalidad, sin llegar al detalle del diseño.

Los elementos de software son una forma abstracta de dominar los componentes o módulos. El sistema se puede mirar desde diferentes perspectivas: hay tres estructuras principales, y en las dos primeras los elementos están presentes, mientras que en la tercera se unen. Una arquitectura llega hasta el nivel de comprender el sistema en su totalidad; pasar a más detalle sería diseño en detalle.

Del libro:
- No todas las estructuras son arquitecturales.
- La arquitectura se enfoca en la parte pública del sistema (interfaces) más que en atributos privados de implementación.
- El objetivo es simplificar el modelado para no entrar en un nivel muy alto de detalle.
- La arquitectura es diseño, pero no todo el diseño es arquitectura.
- Todo sistema de software tiene una arquitectura, porque todos los sistemas tienen relaciones y elementos.
- No todas las arquitecturas son buenas.
