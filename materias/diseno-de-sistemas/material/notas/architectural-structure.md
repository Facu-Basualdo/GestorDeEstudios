# Architectural Structure

> Una estructura es arquitectónica si permite razonar sobre el sistema y sus propiedades, en particular sobre atributos importantes para algún stakeholder.

Aunque el software comprende una provisión interminable de estructuras, no todas son arquitectónicas. Por ejemplo, el conjunto de líneas de código fuente que contienen la letra "z", ordenadas de menor a mayor longitud, es una estructura de software, pero no es interesante ni arquitectónica.

Una estructura es arquitectónica si apoya el razonamiento sobre el sistema y las propiedades del sistema. Ese razonamiento debe ser sobre un atributo importante para algún stakeholder, como la funcionalidad lograda, la capacidad de seguir operando de manera útil ante fallas o intentos de derribarlo, la facilidad o dificultad de hacer cambios específicos, o la capacidad de respuesta a pedidos de los usuarios.

El conjunto de estructuras arquitectónicas no es fijo ni limitado: lo arquitectónico depende de qué sea útil razonar en tu contexto para tu sistema.
