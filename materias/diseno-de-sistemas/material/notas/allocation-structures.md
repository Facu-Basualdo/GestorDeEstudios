# Allocation Structures

> Las allocation structures (estructuras de asignación) establecen el mapeo desde las estructuras de software hacia las estructuras que no son de software, como la organización, los entornos de desarrollo, prueba y ejecución.

Responden preguntas como:

- ¿En qué procesador(es) ejecuta cada elemento de software?
- ¿En qué directorios o archivos se almacena cada elemento durante desarrollo, prueba y system building?
- ¿Cuál es la asignación de cada elemento de software a los equipos de desarrollo?

Entre las allocation structures útiles se encuentran deployment structure, implementation structure y work assignment structure.
