# Tactics-Based Questionnaire for Testability

> Cuestionario basado en tácticas que el analista usa para relevar las decisiones arquitectónicas que soportan la testability.

A partir de las tácticas de la Sección 12.2, se crea un conjunto de preguntas inspiradas en tácticas. Para obtener una visión de las decisiones arquitectónicas, el analista hace cada pregunta y registra las respuestas en una tabla. Las respuestas pueden convertirse en el foco de actividades posteriores: investigación de documentación, análisis de código u otros artefactos, reverse engineering del código, etc.
