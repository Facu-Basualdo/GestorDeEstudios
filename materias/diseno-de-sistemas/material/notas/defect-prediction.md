# Defect Prediction

> La predicción de defectos utiliza técnicas estadísticas para examinar las relaciones entre combinaciones de métricas de software y componentes que contienen defectos conocidos, permitiendo identificar rápidamente clases propensas a defectos.

La predicción de defectos es una parte importante para identificar componentes de software que pueden tener problemas de calidad. Los modelos de predicción de defectos utilizan técnicas estadísticas para examinar las relaciones entre combinaciones de métricas de software y componentes de software que contienen defectos conocidos. Pueden ser una forma eficiente y efectiva para que los desarrolladores de software identifiquen rápidamente clases propensas a defectos. Esto puede reducir costos y tiempos de desarrollo.
