# Offloading Functionality to the Cloud

> Descargar funcionalidad a la nube consiste en ejecutar parte de una aplicación en el sistema móvil, donde están los sensores, y parte en la nube, donde hay más almacenamiento de datos y procesadores más potentes.

El arquitecto debe determinar si el sistema móvil tiene suficiente potencia para ciertas funciones, si hay conectividad adecuada para descargar algunas y cómo satisfacer los requisitos de rendimiento cuando las funciones están divididas. También debe considerar el almacenamiento de datos disponible localmente, los intervalos de actualización de datos y las preocupaciones de privacidad.
