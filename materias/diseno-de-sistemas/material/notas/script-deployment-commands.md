# Script Deployment Commands

> Script deployment commands es una táctica de deployability que consiste en escribir scripts para ejecutar automáticamente los pasos de un despliegue complejo.

Los despliegues son complejos y requieren muchos pasos orquestados con precisión; por eso suelen scriptearse. Estos scripts deben tratarse como código: documentados, revisados, probados y versionados. Un motor de scripting ejecuta el script automáticamente, ahorrando tiempo y minimizando errores humanos.
