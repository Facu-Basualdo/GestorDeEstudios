# Posibilitar el siguiente esfuerzo es el objetivo secundario

> Su producto puede ser considerado una falla aun cuando su equipo entregue un sistema trabajando al usuario si no es lo suficientemente robusto para ser extendido.

Su producto puede ser considerado una falla aun cuando su equipo entregue un sistema trabajando al usuario. Parte del cumplimiento de las necesidades del usuario es asegurar que el sistema es lo suficientemente robusto como para ser extendido a través del tiempo. El siguiente esfuerzo puede ser el desarrollo de una versión mayor de su sistema, o simplemente puede ser la operación y soporte de la aplicación. Para posibilitar esto no solo es importante desarrollar software de calidad sino también crear la documentación suficiente y material de soporte para que las personas involucradas en la próxima etapa del sistema puedan desarrollar su objetivo efectivamente.
