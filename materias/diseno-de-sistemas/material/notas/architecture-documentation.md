# Architecture Documentation

> La documentación de arquitectura es el registro de los resultados de las decisiones de diseño y el vehículo para razonar y comunicar la arquitectura mientras se diseña.

La documentación no tiene que ser un artefacto físico impreso: una wiki en línea que permita discusión, feedback y búsqueda es un ámbito ideal. Tampoco es un paso separado que sigue al diseño: el lenguaje que se usa para explicar la arquitectura a otros también sirve durante el trabajo de diseño. Diseño y documentación son, idealmente, la misma pieza de trabajo. La documentación también es el repositorio de las decisiones de diseño demasiado numerosas e interrelacionadas como para reproducirlas de memoria.
