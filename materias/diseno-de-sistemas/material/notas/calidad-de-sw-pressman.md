# Calidad de SW (Pressman)

> Para Pressman, la calidad del software es un proceso eficaz que dura todo el tiempo, produce un producto útil y tiene un valor medible.

- Es un proceso de SW eficaz.
- Es un proceso que dura todo el tiempo, no un momento determinado.
- El resultado es un producto útil.
- Incluye un valor medible.
