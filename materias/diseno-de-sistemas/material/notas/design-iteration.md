# Design Iteration

> Una design iteration es una unidad de trabajo dentro de un design round en la que se ejecutan pasos de diseño para lograr un objetivo particular.

Cada design iteration se enfoca en lograr un objetivo particular, que suele implicar diseñar para satisfacer un subconjunto de los drivers. Por ejemplo, el objetivo podría ser crear estructuras a partir de elementos que permitan lograr un escenario de performance o un caso de uso. Dentro de cada iteración se realiza una serie de pasos de diseño.
