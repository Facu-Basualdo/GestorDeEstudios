# Change Credential Settings

> Táctica que obliga al usuario a cambiar configuraciones de seguridad por defecto o a elegir una nueva contraseña tras un tiempo máximo.

Muchos sistemas tienen ajustes de seguridad por defecto asignados cuando se entrega el sistema. Forzar al usuario a cambiarlos evita que atacantes accedan a través de ajustes que pueden ser públicos. Muchos sistemas también exigen elegir una nueva contraseña después de un período máximo.
