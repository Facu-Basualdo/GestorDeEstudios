# Security View

> Una security view muestra todas las medidas arquitectónicas tomadas para proveer seguridad.

Representa los componentes que tienen algún rol o responsabilidad de seguridad, cómo se comunican, los repositorios de datos de información de seguridad y los repositorios de interés para la seguridad. Las propiedades de la vista incluyen otras medidas de seguridad (por ejemplo, seguridad física) en el entorno del sistema. También muestra la operación de protocolos de seguridad, dónde y cómo interactúan los humanos con los elementos de seguridad, y cómo responde el sistema ante amenazas y vulnerabilidades específicas.
