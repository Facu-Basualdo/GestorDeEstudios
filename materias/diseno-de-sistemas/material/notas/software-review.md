# Software Review

> Las revisiones de software son un filtro para el flujo de trabajo del proceso de software.

Las revisiones de software son un filtro para el flujo de trabajo del proceso de software. Demasiadas pocas y el flujo está 'sucio'; demasiadas y el flujo se ralentiza. Se aplican en varios puntos durante la ingeniería de software y sirven para descubrir errores y defectos. Las revisiones de software 'purifican' los productos de trabajo, incluidos los modelos de requisitos y diseño, el código y los datos de prueba. Mediante métricas, se puede determinar qué revisiones funcionan y enfatizarlas, al mismo tiempo que se eliminan las revisiones ineficaces del flujo para acelerar el proceso.
