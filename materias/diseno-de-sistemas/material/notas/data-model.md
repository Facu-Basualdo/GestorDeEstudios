# Data Model

> El data model (modelo de datos) describe la estructura de información estática de un sistema en términos de entidades de datos y sus relaciones.

Por ejemplo, en un sistema bancario las entidades suelen incluir Account, Customer y Loan. Account tiene atributos como número de cuenta, tipo (savings o checking), estado y saldo actual. Una relación puede indicar que un customer tiene una o más accounts y una account se asocia con uno o más customers.
