# Prototipo de interfaz de usuario

> Es un artefacto que sirve para validar los casos de uso y ayudar al usuario a comprender visualmente lo que se está desarrollando.

- En el flujo de trabajo de requisitos se usa para validar los casos de uso y ver si se entendieron bien; pueden aparecer nuevos casos de uso.
- La calidad de los interfaces de los prototipos depende de la importancia que tenga la usabilidad.
- Si se quieren probar cosas en profundidad, se necesita un prototipo navegable, que lleva más tiempo y costo.
- Los prototipos pueden ser dibujados a mano alzada o productos navegables, dependiendo de lo que se quiera hacer.
- Sirven principalmente para que el usuario comprenda visualmente lo que se desarrolla y así obtener una retroalimentación mucho más valiosa.
