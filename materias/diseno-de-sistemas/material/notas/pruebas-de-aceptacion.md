# Pruebas de aceptación

> Pruebas de caja negra creadas a partir de historias de usuario en XP para verificar que una funcionalidad se ha implementado correctamente, siendo responsabilidad del cliente.

Las pruebas de aceptación son creadas a partir de las historias de usuario. Durante una iteración, las historias de usuario seleccionadas son trasladadas en pruebas de aceptación. Una historia puede tener una o varias pruebas de aceptación. Las pruebas de aceptación son pruebas de caja negra. Los clientes son responsables de verificar que las pruebas se ejecutan correctamente. Una historia de usuario no se considera completa hasta que no ha superado satisfactoriamente las pruebas de aceptación. El aseguramiento de la calidad es una parte esencial de XP. En otros enfoques el aseguramiento de la calidad puede ser realizado por un equipo independiente. En XP se requiere una relación más estrecha.
