# DMADV

> DMADV es un método de Six Sigma que consta de cinco pasos: definir, medir, analizar, diseñar y verificar.

DMADV se utiliza cuando se está desarrollando un nuevo proceso de software. Los pasos son:
- Definir los requisitos del cliente y las metas del proyecto.
- Medir el proceso actual (si existe) para determinar el rendimiento.
- Analizar las opciones para cumplir con los requisitos.
- Diseñar el proceso para evitar las causas raíz de los defectos y cumplir con los requisitos del cliente.
- Verificar que el modelo de proceso evitará defectos y cumplirá con los requisitos.
