# Establishing Relationships between the Elements

> Establishing Relationships between the Elements es la actividad de ADD que define las relaciones entre los elementos creados y sus propiedades, como qué clientes hablan con qué servidores, mediante qué puertos y protocolos.

La creación de estructuras requiere decidir las relaciones entre elementos y sus propiedades. Usando el patrón client-server, hay que decidir qué clientes se conectan con qué servidores, por qué puertos y protocolos, si la comunicación es síncrona o asíncrona, quién inicia las interacciones y cuánta información se transfiere a qué ritmo. Estas decisiones impactan en atributos de calidad como performance.
