# Comprehensive Notation

> Tipo de notación para documentar comportamiento que muestra el comportamiento completo de los elementos estructurales, permitiendo inferir todos los caminos posibles desde el estado inicial al final.

Las state machines son un tipo de formalismo usado por muchas notaciones comprehensivas. Este formalismo representa el comportamiento de los elementos de la arquitectura porque cada estado es una abstracción de todas las historias posibles que podrían llevar a ese estado. Los lenguajes de state machine permiten complementar una descripción estructural con restricciones sobre interacciones y reacciones temporizadas a estímulos internos y del entorno.
