# Actor de sistema

> Un actor de sistema es externo al sistema; si no se aclara que es de negocio, normalmente es de sistema.

- Los actores del sistema pueden venir de trabajadores de negocio y actores de negocio.
- Están vinculados a los casos de uso de sistema para capturar requisitos funcionales.
