# Review Issues List

> La review issues list es una lista de problemas identificados durante un FTR que sirve como lista de acciones para guiar las correcciones.

La lista de problemas tiene dos propósitos: (1) identificar áreas problemáticas dentro del producto y (2) servir como una lista de verificación de elementos de acción que guía al productor mientras realiza las correcciones. Normalmente se adjunta al informe de resumen.
