# Sensor Hub

> Un sensor hub es un coprocesador que ayuda a integrar datos de diferentes sensores y procesarlos.

Puede descargar (offload) esos trabajos de la CPU principal del producto, lo que ahorra consumo de batería y mejora el rendimiento.
