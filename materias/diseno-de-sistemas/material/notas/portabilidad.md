# Portabilidad

> Facilidad con la que un software diseñado para ejecutarse en una plataforma puede adaptarse para ejecutarse en otra.

Se refiere a la facilidad con la que un software diseñado para ejecutarse en una plataforma puede adaptarse para ejecutarse en otra. Se logra minimizando las dependencias de plataforma, aislando dichas dependencias en ubicaciones bien identificadas y escribiendo el software para que se ejecute en una máquina virtual que encapsula todas las dependencias de plataforma.
