# Favor Object Composition over Class Inheritance

> Principio de diseño orientado a objetos que recomienda priorizar la composición de objetos sobre la herencia de clases para lograr reutilización.

Idealmente no se deberían crear nuevos componentes para reutilizar, sino ensamblar componentes existentes mediante composición. Aunque la herencia facilita la creación de nuevos componentes, la experiencia muestra que los diseñadores abusan de ella. Los diseños se vuelven más reutilizables y simples al depender más de la composición de objetos.
