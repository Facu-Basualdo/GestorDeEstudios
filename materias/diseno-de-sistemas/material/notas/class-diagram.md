# class diagram

> Un class diagram representa clases, su estructura y las relaciones estáticas entre ellas.

La notación de class diagram se basa en OMT (Object Modeling Technique). Una clase se denota con una caja, con el nombre en negrita en la parte superior. Las operaciones clave aparecen debajo del nombre, y las variables de instancia debajo de las operaciones. El tipo itálico indica que la clase u operación es abstracta. Las relaciones estáticas incluyen: herencia (triángulo), agregación (línea con diamante en la base), referencia (línea sin diamante), creación (flecha punteada) y multiplicidad (círculo relleno para 'más de uno'). Además, se usan anotaciones de pseudocódigo para esbozar implementaciones.
