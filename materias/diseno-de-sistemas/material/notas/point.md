# Point

> Point representa un punto en un espacio cartesiano bidimensional y soporta operaciones vectoriales mínimas.

Las coordenadas se definen como typedef float Coord. Las operaciones incluyen constructores, acceso a X e Y, y operadores aritméticos y de comparación sobrecargados. El miembro estático Zero representa Point(0,0).
