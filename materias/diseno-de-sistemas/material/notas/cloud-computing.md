# Cloud Computing

> Cloud computing es la disponibilidad bajo demanda de recursos, en la que los datos y servicios están en computadoras de terceros, accesibles por Internet y con pago por uso.

El término se usa para un amplio rango de capacidades informáticas. Por ejemplo, decir "todas mis fotos están respaldadas en la nube" significa:

- Las fotos están almacenadas en computadoras de otra persona; ellos se ocupan de la inversión de capital, mantenimiento y backups.
- Las fotos son accesibles por Internet.
- Se paga solo por el espacio que se usa o se requisiciona.
- El servicio de almacenamiento es elástico: puede crecer o encogerse según cambian las necesidades.
- El uso es autoprovisionado: se crea una cuenta y se puede empezar a usar inmediatamente.

Las capacidades entregadas desde la nube van desde aplicaciones como almacenamiento de fotos, hasta servicios de grano fino expuestos a través de APIs (por ejemplo, traducción de texto o conversión de moneda), y servicios de infraestructura de bajo nivel como virtualización de procesadores, red y almacenamiento.
