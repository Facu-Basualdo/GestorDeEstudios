# Phase

> La phase de un qubit es un ángulo entre 0 y 2π radianes que describe una rotación; no afecta las probabilidades de la superposición y sirve como otra palanca para manipular qubits.

El valor de la phase es un ángulo entre 0 y 2π radianes. No afecta las probabilidades de la superposición, pero da otra palanca para manipular qubits. Algunos algoritmos cuánticos marcan ciertos qubits manipulando su phase.

Las phases se gestionan haciendo que las amplitudes (probabilidades) sean números complejos.
