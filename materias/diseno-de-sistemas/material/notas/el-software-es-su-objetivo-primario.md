# El software es su objetivo primario

> El objetivo del desarrollo de software es producir software que cubra las necesidades del usuario en forma efectiva.

El objetivo del desarrollo de software es producir software que cubra las necesidades del usuario en forma efectiva. El objetivo primario no es producir documentación extránea, extráneos artefactos de administración, o aún modelos. Cualquier actividad que no contribuya directamente a este objetivo debe ser cuestionada y evitada.
