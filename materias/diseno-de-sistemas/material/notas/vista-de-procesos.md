# Vista de Procesos

> La vista de procesos muestra, en tiempo de ejecución, cómo el sistema se compone de procesos y sirve para comprobar requisitos no funcionales como rendimiento y disponibilidad.

- Es una de las cuatro perspectivas fundamentales del modelo **Vistas 4+1**.
- Muestra en tiempo de ejecución cómo el sistema se compone de procesos.
- Sirve para comprobar requisitos no funcionales como **rendimiento** y **disponibilidad**.
- En los apuntes de clase se asocia con los elementos arquitecturales que se ven en ejecución.
