# Evaluation by the Architect

> La evaluación por el arquitecto es la evaluación que ocurre implícita o explícitamente cada vez que el arquitecto toma una decisión de diseño clave para abordar un ASR o completa un hito de diseño.

La evaluación se realiza —implícita o explícitamente— cada vez que el arquitecto toma una decisión de diseño clave para abordar un ASR o completa un hito de diseño. Esta evaluación implica decidir entre las alternativas en competencia. La evaluación por el arquitecto es una parte integral del proceso de diseño de la arquitectura.
