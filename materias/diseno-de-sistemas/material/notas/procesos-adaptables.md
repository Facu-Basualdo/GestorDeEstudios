# Procesos Adaptables

> Procesos de desarrollo de software que abrazan el cambio y se adaptan a él, utilizando desarrollo iterativo para obtener retroalimentación frecuente.

Los procesos adaptables son una alternativa a los procesos predictivos. Se basan en el desarrollo iterativo para controlar lo impredecible, produciendo versiones operacionales frecuentes que implementan un subconjunto de características. Requieren una relación cercana con el cliente, quien tiene control fino sobre el desarrollo. No funcionan con contratos de precio fijo. Ejemplos de duración de iteraciones: XP sugiere 1-3 semanas, SCRUM un mes.
