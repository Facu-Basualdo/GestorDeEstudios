# Genetic Algorithm

> Un algoritmo genético es un método de búsqueda heurística utilizado en inteligencia artificial y computación para encontrar soluciones casi óptimas a problemas de búsqueda basado en la teoría de la selección natural y la biología evolutiva.

Los algoritmos genéticos se pueden utilizar para hacer crecer modelos de confiabilidad descubriendo relaciones en datos históricos del sistema. Estos modelos se han utilizado para identificar componentes de software que podrían fallar en el futuro. A veces, estos modelos se han creado basados en métricas estimadas a partir de modelos UML antes de que se escriba ningún código. Este tipo de trabajo es muy importante para los desarrolladores interesados en refactorizar productos de software o reutilizar componentes de software en otros productos.
