# Implementar una Clase

> Actividad del flujo de implementación que codifica en el lenguaje elegido las clases de diseño, con sus operaciones y métodos.

Hay que integrar las clases en el lenguaje que se eligió. Para cada operación que se elija, hay que codificar el método. El ingeniero de componentes haría el rol de programador. Subactividades: esbozo de los componentes fichero, generación de código a partir de una clase de diseño e implementación de operaciones.
