# Controllability

> Controllability es la capacidad de un sistema para que sus entradas (y posiblemente su estado interno) puedan ser controladas durante las pruebas.

Es una condición para que un sistema sea propiamente testeable. Frecuentemente se logra mediante un test harness. Una de las dos categorías de tactics for testability se ocupa de agregar controllability y observability al sistema.
