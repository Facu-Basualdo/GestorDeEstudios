# Caso de uso de negocio

> Un caso de uso de negocio modela procesos del negocio.

- Se diferencia del caso de uso de sistema en que el de negocio modela procesos del negocio.
- El actor de negocio es externo al negocio y se suele confundir con el trabajador.
- Los casos de uso de sistema se derivan de los casos de uso de negocio.
