# Diseño

> Disciplina del Proceso Unificado en la que el modelo alcanza el nivel de detalle máximo y aparecen explícitamente las interfaces.

En la disciplina de diseño empieza a aparecer explícitamente el concepto de interfaces, ya sea entre clases y sobre todo entre subsistemas; las interfaces se tratan como clasificador, no como estereotipo frontera.
El diseño es un modelo con el suficiente nivel de detalle para que se entienda la flexibilidad de uso.
El modelo de diseño es más costoso que el de análisis por tener mayor detalle.
Se trabaja con el lenguaje que se va a utilizar, pero no se llega a hacer todo.
Mientras más formal, menos ambigüedad.
