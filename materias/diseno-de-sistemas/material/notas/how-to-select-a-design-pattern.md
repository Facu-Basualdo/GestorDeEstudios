# How to Select a Design Pattern

> Conjunto de enfoques para encontrar el patrón de diseño adecuado para un problema particular.

Existen seis enfoques para seleccionar un patrón de diseño:
1. Considerar cómo los patrones resuelven problemas de diseño.
2. Escanear las secciones de Intención.
3. Estudiar cómo se interrelacionan los patrones.
4. Estudiar patrones de propósito similar.
5. Examinar una causa de rediseño.
6. Considerar qué debería ser variable en el diseño.
