# Architecture Evaluation

> La architecture evaluation (evaluación de arquitectura) es el proceso de determinar el grado en que una arquitectura es apta para el propósito para el que fue concebida.

La arquitectura es un contribuyente tan importante para el éxito de un sistema y de un proyecto de ingeniería de software que tiene sentido detenerse y asegurarse de que la arquitectura que se está diseñando podrá proveer todo lo que se espera de ella. La evaluación se basa en analizar las alternativas. Para que sea útil, el costo de la evaluación debe ser menor que el valor que provee. Los costos de las distintas técnicas de evaluación se pueden medir en términos del tiempo que las personas involucradas dedican a la preparación, ejecución y seguimiento de las actividades.
