# Considerar la prueba del sistema

> Al modelar, preguntarse constantemente cómo se probará, ya que si no se puede probar no debería construirse.

Cuando se modela debe preguntarse constantemente '¿como probaremos esto?' porque si no puede probarse el software no debería construirlo. Los procesos de software modernos incluyen las actividades de prueba y aseguramiento de la calidad a lo largo de todo el ciclo de vida del proyecto y muchos promueven escribir la prueba antes de escribir el software (esto es una práctica de XP).
