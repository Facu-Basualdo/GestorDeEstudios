# Modelar con otros

> El equipo necesita trabajar conjuntamente para crear modelos centrales críticos, desarrollando una solución con la que todos estén de acuerdo y la más simple.

A menudo encontrará que su equipo de desarrollo necesita trabajar conjuntamente para crear un conjunto de modelos centrales críticos para su proyecto. Por ejemplo para desarrollar la arquitectura base del sistema, deberá trabajar con un grupo de gente para desarrollar una solución con la que todos estén de acuerdo, como también la solución mas simple.
