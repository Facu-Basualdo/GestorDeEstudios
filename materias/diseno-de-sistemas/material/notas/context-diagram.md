# Context Diagram

> Diagrama que muestra cómo el sistema o una porción del sistema se relaciona con su entorno, con el propósito de representar el alcance de una vista.

Aquí "contexto" significa un entorno con el cual la (parte del) sistema interactúa. Las entidades del entorno pueden ser humanos, otros sistemas informáticos u objetos físicos, como sensores o dispositivos controlados. Se puede crear un context diagram para cada vista, mostrando cómo distintos tipos de elementos interactúan con el entorno del sistema. Son útiles para presentar una imagen inicial de cómo un sistema o subsistema interactúa con su entorno.
