# UML Communication Diagram

> Diagrama UML que muestra un grafo de elementos que interactúan y anota cada interacción con un número que denota su orden.

Al igual que los sequence diagrams, las instancias que se muestran son elementos descriptos en la documentación estructural asociada. Son útiles para verificar que una arquitectura puede cumplir con los requisitos funcionales. No son útiles cuando importa comprender acciones concurrentes, como en un análisis de performance.
