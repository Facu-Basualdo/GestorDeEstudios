# Proceso de desarrollo de software

> Es un proceso que guía y organiza las tareas de un equipo de desarrollo: quién hace las cosas, qué actividades se realizan, qué se produce y en qué orden.

Un proceso de desarrollo es necesario para organizar las tareas que se van a hacer y para que alguien guíe al equipo. Define:
- **Quién** hace las cosas.
- **Qué** actividades se van a hacer.
- **Qué** se produce en cada actividad (los artefactos).
- **Cuándo** se hacen, es decir, la secuencialidad.

El **cómo** ya sería demasiado prescriptivo y no todos los procesos lo incluyen. Los autores recomiendan ciertas actividades que terminan en ciertos tipos de artefactos. El proceso debe poder evolucionar y adaptarse a las tecnologías que van surgiendo, sin quedar atado a una tecnología en particular.
