# Bayesian Inference

> La inferencia bayesiana es un método de inferencia estadística en el que se utiliza el teorema de Bayes para actualizar la probabilidad de una hipótesis a medida que se dispone de más evidencia o información.

En el contexto de confiabilidad del software, la inferencia bayesiana se puede usar para estimar cantidades probabilísticas utilizando datos históricos incluso cuando falta alguna información. El uso de técnicas bayesianas ha permitido soluciones en tiempo real a problemas de estimación de probabilidad que están más allá del razonamiento humano.
