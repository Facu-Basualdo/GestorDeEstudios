# Componente de prueba

> El componente de prueba es el artefacto que permite tratar de automatizar las pruebas.

Las pruebas más automatizables son los test unitarios; las menos automatizables son las de usabilidad. El componente de prueba también se usa para tratar de sobrecargar el sistema lo más que se pueda y ver cómo funciona en base a eso.
