# Review Metrics

> Review metrics are a set of measures used to assess the efficacy of technical reviews, including preparation effort, assessment effort, rework effort, review effort, work product size, minor and major errors found, total errors, and error density.

The following review metrics can be collected for each review:
- Preparation effort, Ep
- Assessment effort, Ea
- Rework effort, Er
- Review effort, Ereview = Ep + Ea + Er
- Work product size (WPS)
- Minor errors found, Errminor
- Major errors found, Errmajor
- Total errors found, Errtot = Errminor + Errmajor
- Error density = Errtot / WPS
These metrics can be used to compute error density and estimate errors in a new document. They also enable assessment of cost effectiveness.
