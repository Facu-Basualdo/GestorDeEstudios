# Software Quality

> An effective software process applied in a manner that creates a useful product that provides measurable value for those who produce it and those who use it.

This definition emphasizes three important points:

1. **Effective software process**: establishes the infrastructure that supports any effort at building a high-quality software product. Management aspects create checks and balances to avoid project chaos. Software engineering practices allow analysis and design of solid solutions. Umbrella activities like change management and technical reviews are critical.
2. **Useful product**: delivers content, functions, and features that the end user desires, in a reliable, error-free way. It satisfies explicit and implicit requirements (e.g., ease of use).
3. **Added value**: high-quality software provides benefits for both producer and user. The software organization gains less maintenance, fewer bug fixes, reduced customer support. The user community gains a useful capability that expedites business processes, resulting in greater revenue, profitability, and availability of crucial information.
