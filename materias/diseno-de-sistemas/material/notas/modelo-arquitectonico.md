# Modelo arquitectónico de un programa

> Modelo que representa un programa y que se utiliza de dos maneras: para fomentar el debate sobre el diseño del sistema o para documentar una arquitectura diseñada.

Como medio para fomentar el debate: es abstracto y de alto nivel, sirve para comunicarse con los stakeholders, planificar proyectos y asignar tareas. Como medio para documentar una arquitectura diseñada: genera un modelo completo con componentes, interfaces y conexiones, lo que facilita la comprensión y evolución del sistema.
