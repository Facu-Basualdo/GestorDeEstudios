# How to Use a Design Pattern

> Guía paso a paso para aplicar un patrón de diseño una vez seleccionado.

Pasos para usar un patrón de diseño:
1. Leer el patrón una vez para tener una visión general.
2. Estudiar las secciones de Estructura, Participantes y Colaboraciones.
3. Mirar la sección de Código de Ejemplo.
4. Elegir nombres significativos para los participantes.
5. Definir las clases.
6. Definir nombres específicos de la aplicación para las operaciones.
7. Implementar las operaciones.
Además, se advierte que los patrones no deben aplicarse indiscriminadamente; solo cuando la flexibilidad sea necesaria.
